# 발표 디자인 하우스 스타일

과학·기술 발표 기본값. **글보다 이미지 중심, 세련되고 깔끔하게.**

## 핵심 원칙

- **이미지가 주연, 텍스트는 조연.** 슬라이드마다 강한 시각 요소 1개 이상. 글머리표만 있는 슬라이드 금지.
- **다크 스페이스 테마**를 기본으로(우주/물리/공학과 잘 맞고 프리미엄해 보임). 전 슬라이드 일관 유지.
- **시각 모티프 1개를 끝까지 반복.** 예: Artemis 덱은 슬라이드마다 천체(달·지구·화성)를 원형으로 화면 가장자리에 배치.
- **여백을 둔다.** 가장자리 최소 0.5", 블록 간 0.3~0.5".

## 색 (다크 베이스)

| 역할 | HEX |
|------|-----|
| 배경 (deep space navy) | `0B0F1A` |
| 패널 | `151B2B` |
| 밝은 패널 | `1C2740` |
| 본문 텍스트 | `FFFFFF` |
| 보조 텍스트 (cool grey) | `AEB7C7` |
| 강조 (lunar amber) | `F2A93B` |
| 라인/테두리 | `2A3550` |

> 강조색은 주제에 맞게 1개만. 우주=amber, 그 외 주제는 바꿔도 됨(파랑 남발 금지).

## 타이포

- 제목: **Trebuchet MS** Bold / 본문: **Calibri** (둘 다 Windows·PowerPoint 기본 탑재)
- 크기: 표지 제목 54~60pt · 슬라이드 제목 31~33pt · 섹션 헤더 20~22pt · 본문 15~19pt · 캡션 9~11pt
- 제목 위 **킥커**(섹션 라벨)는 amber, 대문자, `charSpacing: 3`.

## 레이아웃 패턴 (슬라이드마다 바꿀 것)

- 표지/결론: 다크 배경 + 천체 원형 이미지 + 좌측 텍스트
- 풀블리드 이미지 + 좌측 반투명 패널 위 텍스트(콘셉트 아트 등 가로 이미지)
- 우측 이미지 패널 + 좌측 카드 2~3개(아이콘 원 + 헤더 + 설명)
- 좌측 인물/사진 반블리드 + 우측 아이콘 행 목록

## 하면 안 되는 것 (AI 슬라이드 티)

- 제목 밑줄 액센트 라인 ❌
- 장식용 풀폭 컬러 바/리본 ❌
- 크림·베이지 배경 ❌ (다크 또는 흰색만)
- 같은 레이아웃 반복 ❌
- 본문 가운데 정렬 ❌ (제목만 가운데)
- 다크 테마에 흰 배경 도표 이미지 섞기 ❌ (사진을 잘라 쓰거나 깔끔한 것만)

## 이미지

- 출처: Wikimedia Commons / NASA(퍼블릭 도메인 우선). 받기 전 한 장씩 눈으로 확인.
- 1600px 이상 받아서 cover로 크롭. 천체는 `rounding: true`로 원형 처리.
- 라벨·격자가 박힌 도표는 쓰지 말 것. 필요하면 깨끗한 사진의 일부를 `sharp`로 잘라 텍스처 패널로.

## 빌드 함정 (pptxgenjs)

- HEX에 `#` 금지, 8자리(투명도 포함) HEX 금지 → 파일 깨짐. 투명도는 `opacity`/`transparency`로.
- `shadow` 객체는 호출마다 새로 생성(재사용 시 두 번째 도형 깨짐).
- 글머리표는 `bullet: true`, 줄바꿈은 `breakLine: true`. 유니코드 `•` 금지.
