## 한 줄 요약
**표현식(값을 계산)**과 **문장(동작을 수행)**을 구분하고, 연산자의 종류·**우선순위·결합성**, 그리고 **형변환**(암시적 승격 vs 명시적 `static_cast`)을 정확히 다루는 장.

---

## 3.1 표현식 vs 문장
- **표현식(expression)**: 평가하면 **값**이 나오는 것 — `a + 3`, `x > 0`, `++i`
- **문장(statement)**: 동작 단위. 보통 `;`로 끝남
  - 표현식 문장: `x = a + 3;`
  - 선언 문장: `int n = 5;`
  - 복합 문장(블록): `{ ... }`
```cpp
3 + 4;        // 유효한 표현식 문장(값은 버려짐)
int y = 3 + 4; // 표현식의 값을 변수에 저장
```

## 3.2 연산자의 종류
| 분류 | 연산자 | 결과 |
|---|---|---|
| 산술 | `+ - * / %` | 수치 (`%`는 정수 나머지) |
| 관계 | `< <= > >= == !=` | `bool` |
| 논리 | `&& \|\| !` | `bool` (단축 평가) |
| 비트 | `& \| ^ ~ << >>` | 정수 비트 연산 |
| 대입 | `=` 와 복합대입 | 좌변에 저장 |

```cpp
int r = 17 % 5;          // 2
bool b = (x > 0) && (y < 10);  // x>0 거짓이면 y 평가 안 함(단축)
int mask = 0b1010 & 0b0110;    // 0b0010
```

## 3.3 우선순위와 결합성
- **우선순위(precedence)**: `*`,`/`,`%`가 `+`,`-`보다 먼저
- **결합성(associativity)**: 같은 우선순위일 때 묶는 방향
  - 산술/관계 등 대부분 **왼→오**
  - 대입 `=`은 **오→왼**: `a = b = 3;` → `b=3` 먼저
```cpp
int v = 2 + 3 * 4;   // 14 (곱 먼저)
int w = (2 + 3) * 4; // 20
```
> 헷갈리면 괄호로 명시 — 가독성·정확성 둘 다 이득.

## 3.4 형변환
### 암시적 변환(승격, promotion)
표현식 안에서 작은 타입이 큰 타입으로 자동 승격.
```cpp
int    i = 7;
double d = i / 2;     // 3.0! 정수끼리 나눠 3 → double로 승격
double e = i / 2.0;   // 3.5  한쪽이 double이면 실수 나눗셈
```
### 명시적 변환 — static_cast
```cpp
double pi = 3.99;
int n = static_cast<int>(pi);   // 3 (소수부 버림, 반올림 아님)
double avg = static_cast<double>(sum) / count;
```
- C 스타일 `(int)pi`보다 `static_cast`가 검색·검사에 유리해 권장

## 3.5 부수효과와 증감 연산
- **부수효과(side effect)**: 표현식이 값 외에 상태를 바꾸는 것 (`=`, `++`, `--`)
```cpp
int i = 5;
int a = i++;   // a=5, 그 후 i=6 (후위: 먼저 쓰고 증가)
int b = ++i;   // i=7 먼저, b=7 (전위)
```
> `a[i] = i++;`처럼 한 표현식에서 같은 변수를 두 번 변경하면 미정의 동작 — 피할 것.

## 3.6 복합대입과 문장 종류
```cpp
x += 5;   // x = x + 5
x *= 2;   // x = x * 2
x %= 3;   // x = x % 3
```
- 문장 분류: 표현식 문장 · 선언 문장 · **복합문(블록)** · 선택문(Ch4) · 반복문(Ch5) · 점프문(`break`,`continue`,`return`)

## 자주 하는 실수
- `int / int`가 정수 나눗셈인 걸 잊어 `1/2 == 0`
- `%`를 실수에 사용 (피연산자는 정수여야 함)
- `=`(대입)과 `==`(비교) 혼동
- 전위/후위 증감의 반환값 차이 무시
- 우선순위 착각 — `a & b == c`는 `a & (b==c)` (비트 `&`가 `==`보다 낮음)

## 연습문제
1. `int v = 2 + 3 * 4 % 5;`의 값을 우선순위에 따라 단계별로 계산하라.
2. `int i = 5; int a = i++ + ++i;` 실행 후 `a`와 `i`의 값을 구하라.
3. 섭씨를 화씨로 바꾸는 식 `f = c * 9 / 5 + 32`에서 `c`가 `int`일 때 생기는 정수 나눗셈 문제를 지적하고 `static_cast`로 고쳐라.
> 힌트: 1번은 `%`가 `*`,`/`와 같은 우선순위(왼→오 결합)임에 주의.
