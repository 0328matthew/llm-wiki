## 한 줄 요약
**배열**은 같은 타입의 원소를 연속 메모리에 모아 인덱스로 접근하는 자료형. 인덱스는 **0부터** 시작하고, 배열을 함수에 넘기면 **포인터처럼 전달**되어 원본을 공유한다. 경계 검사가 없으므로 넘침이 곧 버그다. 안전한 대안으로 `std::array`가 있다.

---

## 8.1 1차원 배열 — 선언·초기화·인덱싱
```cpp
int a[5];                    // 미초기화 (쓰레기값)
int b[5] = {1, 2, 3, 4, 5};  // 전체 초기화
int c[5] = {1, 2};           // 나머지는 0
int d[]  = {1, 2, 3};        // 크기 자동 추론 (3)
```
- 인덱스 범위는 `0 ~ size-1`. `b[0]`이 첫 원소, `b[4]`가 마지막.
- 배열 이름은 첫 원소의 **주소**로 변환됨: `b == &b[0]`.

```cpp
for (int i = 0; i < 5; ++i)
    std::cout << b[i] << ' ';
```

## 8.2 배열과 함수 — 참조처럼 전달
- 배열 인자는 **포인터로 전달**(decay)되므로 함수 안에서 수정하면 원본이 바뀜. 크기 정보는 사라지므로 **별도 인자**로 넘긴다.

```cpp
void scale(int arr[], int n, int k) {  // int* arr 와 동일
    for (int i = 0; i < n; ++i)
        arr[i] *= k;                    // 원본 변경됨
}

int v[3] = {1, 2, 3};
scale(v, 3, 10);   // v == {10, 20, 30}
```
> `sizeof(arr)`는 함수 안에서 포인터 크기일 뿐 배열 전체 크기가 아니다.

## 8.3 2차원·다차원 배열
```cpp
int m[2][3] = { {1, 2, 3},
                {4, 5, 6} };   // 2행 3열
m[1][2] = 99;                  // 2행 3열 원소
```
- 메모리에는 **행 우선(row-major)**으로 연속 저장.
- 함수 인자로 넘길 때 **첫 차원 외 크기는 명시** 필수: `void f(int g[][3], int rows)`.

## 8.4 객체 배열
```cpp
class Point {
    int x, y;
public:
    Point() : x(0), y(0) {}
    Point(int a, int b) : x(a), y(b) {}
};

Point pts[3];                              // 각 원소 기본 생성자 호출
Point line[2] = { Point(0,0), Point(1,1) }; // 명시적 초기화
```
- 기본 초기화 시 **기본 생성자가 반드시 있어야** 함.

## 8.5 경계 넘침의 위험
```cpp
int a[3] = {1, 2, 3};
a[3] = 10;   // 정의되지 않은 동작! 컴파일러는 막지 않음
```
- C++ 원시 배열은 **경계 검사를 하지 않는다** → 버퍼 오버런, 메모리 손상의 원흉.
- 반복문 조건(`< n` vs `<= n`)에서 한 칸 넘침(off-by-one)이 흔하다.

## 8.6 `std::array` 간단 소개
```cpp
#include <array>
std::array<int, 3> a = {1, 2, 3};
a.at(5);          // 범위 밖이면 예외 발생 (안전)
a.size();         // 크기 정보 보존
```
- 원시 배열과 달리 **크기를 기억**하고, 함수에 값/참조로 넘겨도 정보가 유지되며 `.at()`은 경계 검사를 한다.

---

## 자주 하는 실수
- 인덱스를 1부터로 착각 → 첫/마지막 원소 누락 또는 넘침.
- `arr.length`/`size()`가 없는 원시 배열에서 길이를 추측.
- 함수 안에서 `sizeof(arr)`로 배열 크기를 구하려 함(포인터 크기가 나옴).
- 2차원 배열 함수 인자에서 열 크기 생략.
- 경계 밖 쓰기를 "조용히 동작하니 괜찮다"고 오해.
