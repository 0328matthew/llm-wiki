## 한 줄 요약
자료구조는 데이터를 **무엇을 할 수 있는가(인터페이스)**와 **어떻게 저장하는가(구현)**로 분리해 본다. **ADT** 개념 위에 연결리스트·스택·큐·트리를 얹고, 각 연산의 **시간복잡도**로 비교한다.

---

## 18.1 추상 자료형 (ADT)
**ADT(Abstract Data Type)**는 데이터 + 그 위에서 허용된 연산의 집합을 **구현과 분리해** 정의한 것.
- 사용자는 "스택은 push/pop/top을 가진다"만 알면 됨 (캡슐화)
- 내부가 배열인지 연결리스트인지는 숨김 → 구현 교체 자유
- C++에서는 보통 **클래스**로 ADT를 표현 (private 데이터 + public 멤버 함수)

## 18.2 연결 리스트 (Linked List)
노드들이 **포인터로 연결**된 구조. 동적 크기, 중간 삽입/삭제가 O(1)(위치를 알 때).
```cpp
struct Node {
    int data;
    Node* next;
};
```
- **단일 연결(singly)**: 다음 노드만 가리킴 → 앞으로만 순회
- **이중 연결(doubly)**: `prev`, `next` 둘 다 → 양방향 순회, 삭제 편리
```cpp
struct DNode {
    int data;
    DNode* prev;
    DNode* next;
};
```
배열과 달리 인덱스 임의 접근은 불가(O(n) 순회 필요).

## 18.3 스택과 큐
| 구조 | 규칙 | 핵심 연산 | 비유 |
|---|---|---|---|
| **스택(Stack)** | LIFO (후입선출) | push / pop / top | 접시 더미 |
| **큐(Queue)** | FIFO (선입선출) | enqueue / dequeue / front | 줄 서기 |
- 스택: 함수 호출 스택, 괄호 검사, 되돌리기(undo)
- 큐: 작업 스케줄링, BFS 탐색, 버퍼
스택은 한쪽 끝에서만, 큐는 한쪽에서 넣고 반대쪽에서 뺀다.

## 18.4 트리와 이진 트리
**트리**는 계층적(부모-자식) 구조, 사이클이 없음. 루트에서 시작해 가지로 뻗음.
- **이진 트리(binary tree)**: 각 노드가 자식 최대 2개(left, right)
- **이진 탐색 트리(BST)**: 왼쪽 < 부모 < 오른쪽 → 평균 O(log n) 검색
```cpp
struct TreeNode {
    int data;
    TreeNode* left;
    TreeNode* right;
};
```
순회: 전위(preorder)·중위(inorder)·후위(postorder) — 재귀로 자연스럽게 구현([[OOP Ch17 재귀]]).

## 18.5 시간 복잡도 직관 (Big-O)
입력 크기 n이 커질 때 연산 횟수의 **증가율**을 표기.
| 표기 | 이름 | 예 |
|---|---|---|
| O(1) | 상수 | 배열 인덱스 접근 |
| O(log n) | 로그 | 이진 검색, 균형 BST |
| O(n) | 선형 | 리스트 순회 |
| O(n log n) | 선형로그 | 효율적 정렬 |
| O(n²) | 제곱 | 단순 이중 루프 |
상수 계수·낮은 차수 항은 무시하고 **지배항**만 본다.

## 18.6 배열 기반 vs 포인터 기반
| 항목 | 배열 기반 | 포인터(노드) 기반 |
|---|---|---|
| 임의 접근 | O(1) | O(n) |
| 삽입/삭제(중간) | O(n) 이동 | O(1) (위치 알 때) |
| 크기 | 고정/재할당 | 동적 |
| 메모리 | 연속, 캐시 친화 | 포인터 오버헤드 |
같은 ADT라도 구현 선택에 따라 성능 특성이 달라진다.

## 자주 하는 실수
- 연결리스트 노드 `delete` 누락 → 메모리 누수, 또는 dangling 포인터 접근
- 노드 삭제 시 `next` 연결을 끊기 전에 메모리 해제 → 리스트 유실
- 스택(LIFO)과 큐(FIFO)를 혼동
- 빈 리스트/스택에서 pop·top 호출(경계 검사 누락)
- Big-O를 실제 실행 시간으로 오해 — 상수 인자/입력 크기를 무시

## 연습문제
1. `push_front`와 `print`를 갖춘 단일 연결 리스트를 직접 구현하라.
2. 고정 크기 배열로 스택(`push`/`pop`/`top`)을 구현하고 오버플로를 처리하라.
3. 같은 입력 순서로 스택과 큐에 넣고 꺼낼 때 출력 순서가 어떻게 다른지 비교하라(LIFO vs FIFO).
> 힌트: 3번에서 스택은 역순, 큐는 입력 순서대로 나온다.
