## 한 줄 요약
같은 작업을 조건이 참인 동안 반복하는 **루프**: 사전검사형 `while`/`for`와 사후검사형 `do-while`, 구성요소(초기화·조건·갱신), 그리고 `break`/`continue`로 흐름을 미세 조정하는 장.

---

## 5.1 루프의 세 구성요소
모든 반복은 **초기화 → 조건 검사 → 본문 → 갱신**의 순환.
- 초기화를 빠뜨리면 쓰레기값으로 시작
- 갱신을 빠뜨리면 **무한루프**

## 5.2 while — 사전검사
```cpp
int i = 0;              // 초기화
while (i < 5) {         // 조건(먼저 검사)
    cout << i << " ";
    ++i;                // 갱신
}
```
- 조건을 **본문 실행 전에** 검사 → 처음부터 거짓이면 0번 실행

## 5.3 do-while — 사후검사
```cpp
int n;
do {
    cout << "양수 입력: ";
    cin >> n;
} while (n <= 0);       // 본문 실행 후 검사
```
- 본문을 **최소 한 번**은 실행. 입력 검증·메뉴에 적합
- `while (...)` 뒤 세미콜론 필수

## 5.4 for — 셋을 한 줄에
```cpp
for (int i = 0; i < n; ++i) {   // 초기화; 조건; 갱신
    sum += i;
}
```
- 반복 횟수가 정해진 경우에 가장 명확
- `i`는 `for` 헤더 범위 안에서만 유효(블록 범위)
- 세 부분 모두 생략 가능: `for (;;) {}`는 무한루프

## 5.5 중첩 루프
```cpp
for (int r = 1; r <= 3; ++r) {
    for (int c = 1; c <= 3; ++c)
        cout << r * c << '\t';
    cout << '\n';
}
```
- 바깥 1회마다 안쪽 전체 실행 → 총 실행 = 곱
- 표·행렬 처리에 흔함. 인덱스 이름을 구분(`i`/`j`)

## 5.6 break 와 continue
```cpp
for (int i = 0; i < 10; ++i) {
    if (i == 5) break;     // 루프 즉시 탈출
    if (i % 2 == 0) continue;  // 이번 회차 남은 본문 건너뜀
    cout << i << " ";      // 1 3 출력
}
```
- `break`: 가장 안쪽 루프 하나만 빠져나감
- `continue`: `for`에서는 **갱신식으로** 점프, `while`에서는 조건으로 점프

## 5.7 무한루프와 종료 조건
```cpp
while (true) {
    if (done) break;       // 탈출 경로 필수
}
```
- 의도된 무한루프는 반드시 내부 탈출 조건과 짝
- 의도치 않은 무한루프 원인: 갱신 누락, 잘못된 조건, 부동소수 누적 오차

## 5.8 range-based for (맛보기)
```cpp
int arr[] = {10, 20, 30};
for (int x : arr)          // 원소를 순서대로 x에 복사
    cout << x << " ";
for (int& x : arr) x *= 2; // 참조로 받아 원본 수정
```
- 컨테이너/배열 전체 순회에 인덱스 실수 없이 간결(C++11)

---

## 자주 하는 실수
- `for`/`while` 조건에 `;`를 붙여 빈 본문이 됨: `while (i<5);`
- 갱신식 누락 → 무한루프
- 부호 없는 정수 역방향 카운트 `for (unsigned i=n; i>=0; --i)` — 영원히 참
- `break`가 모든 중첩 루프를 빠져나간다고 오해(하나만)
- 부동소수 카운터로 정확한 반복 횟수 기대

## 연습문제
1. `for`와 `while` 두 가지 방식으로 1~100의 합을 각각 구하라.
2. 사용자가 0을 입력할 때까지 정수를 받아 개수와 평균을 출력하라(개수를 미리 모르는 사건 제어 루프).
3. 중첩 `for`로 2~9단 구구단을 표 형태로 출력하라.
> 힌트: 2번은 입력 개수를 모르므로 `while (cin >> n && n != 0)` 패턴이 자연스럽다.
