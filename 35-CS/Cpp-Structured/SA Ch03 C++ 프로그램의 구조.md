## 한 줄 요약
**표현식(expression)**이 어떻게 값으로 평가되는지가 핵심: 연산자 **우선순위·결합성**, **대입의 부수효과**, **형 승격/캐스트**가 결합해 한 줄의 계산 결과를 결정한다. 알고리즘의 "처리" 단계를 정확한 문장으로 옮기는 장.

---

## 3.1 표현식과 문장
- **표현식**: 평가되어 하나의 값을 내는 것 (`a + b`, `x > 0`, `count++`)
- **문장(statement)**: 동작 단위. `;`로 끝남
  - 표현식 문장: `total = a + b;`
  - 선언 문장: `int n;`
  - 복합문(블록): `{ ... }`
- 구조적 프로그램 = 문장이 위→아래로 **순차** 실행되는 흐름

## 3.2 산술 연산자
```cpp
int q = 17 / 5;   // 몫 3 (정수 나눗셈)
int r = 17 % 5;   // 나머지 2 (모듈러스, 정수 전용)
double d = 17.0 / 5;  // 3.4
```
- `+ - * /` 와 정수 전용 `%`
- 단항: `+x`, `-x`

## 3.3 우선순위와 결합성
| 우선순위 | 연산자 | 결합성 |
|---|---|---|
| 높음 | `()` `++` `--`(후위) | 좌→우 |
| | 단항 `+ - !` (전위) | 우→좌 |
| | `* / %` | 좌→우 |
| | `+ -` | 좌→우 |
| | `< <= > >=` | 좌→우 |
| | `== !=` | 좌→우 |
| | `&&` | 좌→우 |
| | `||` | 좌→우 |
| 낮음 | `=` `+=` … | 우→좌 |

예: `a + b * c` = `a + (b*c)`. 헷갈리면 **괄호로 명시**.

## 3.4 대입과 부수효과(side effect)
```cpp
int x = 5;
int y = (x = 10);   // 대입식의 값은 대입된 값 → y = 10
x += 3;             // 복합 대입: x = x + 3
int a = x++;        // 후위: a에 옛값, 그 뒤 x 증가
int b = ++x;        // 전위: x 먼저 증가, 그 값을 b에
```
- `=`는 표현식이며 **값을 가진다** + 변수 상태를 바꾸는 **부수효과**
- 한 문장에 같은 변수를 여러 번 증감하지 말 것 (정의되지 않은 동작)

## 3.5 형변환 — 승격과 캐스트
- **승격(promotion)**: 좁은 형 → 넓은 형 자동 (`int → double`)
- **혼합 표현식**: 한쪽이 `double`이면 다른 쪽도 `double`로 승격 후 계산
  ```cpp
  double avg = sum / 3;       // sum이 int면 정수나눗셈 위험
  double avg2 = sum / 3.0;    // 3.0이 승격 유발 → 실수나눗셈
  ```
- **명시적 캐스트**: `static_cast<double>(n)`

## 3.6 관계·논리 연산자
- **관계**: `< <= > >= == !=` → 결과는 `bool`
- **논리**: `&&`(그리고), `||`(또는), `!`(부정)
- **단축 평가(short-circuit)**: `&&`는 왼쪽이 거짓이면 오른쪽 평가 안 함, `||`는 왼쪽이 참이면 생략
  ```cpp
  if (n != 0 && total / n > 1)   // n==0이면 나눗셈 회피
  ```

## 3.7 입출력 문장 구성
```cpp
cout << "합 = " << a + b << ", 곱 = " << a * b << endl;
cin  >> a >> b;   // 공백/개행으로 구분
```
- `<<` `>>`도 연산자 → 좌→우 결합, 연쇄 가능
- 표현식을 직접 출력하면 중간 변수 없이 결과를 보여줄 수 있다

## 자주 하는 실수
- `==`(비교)와 `=`(대입) 혼동 → `if (x = 5)`는 항상 참
- 정수 나눗셈을 실수 결과로 기대 (`5/2 == 2`)
- 우선순위 착각으로 괄호 누락 → `a + b % c`가 의도와 다름
- 후위/전위 증감의 평가 시점 혼동
- `%`를 실수에 사용 시도 (컴파일 오류)
