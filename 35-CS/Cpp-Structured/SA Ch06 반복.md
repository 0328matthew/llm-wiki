## 한 줄 요약
세 제어 구조의 마지막 — **반복(iteration)**. 같은 작업을 조건이 만족하는 동안 되풀이한다. 모든 루프는 **초기화 · 검사 · 본체 · 갱신**의 네 요소로 설계하며, 종료 조건을 정확히 잡는 것이 핵심이다. 사전검사(`while`/`for`)와 사후검사(`do-while`)를 구분한다.

---

## 6.1 반복의 개념과 루프 설계
모든 올바른 루프는 네 가지를 갖춰야 한다:
1. **초기화(initialization)**: 제어 변수 시작값
2. **검사(condition)**: 계속할지 판단 (참이면 반복)
3. **본체(body)**: 실제 작업
4. **갱신(update)**: 제어 변수를 종료 쪽으로 진행
> 이 중 하나라도 빠지면 무한 루프 또는 한 번도 안 도는 루프가 된다.

## 6.2 사전검사 루프 — while / for
검사를 **본체 실행 전**에 한다 → 조건이 처음부터 거짓이면 본체는 0번 실행.
```cpp
// while: 횟수가 불분명할 때
int n = 1;
while (n <= 5) {       // 검사
    cout << n << " ";
    n++;               // 갱신 (필수!)
}

// for: 횟수가 정해진(카운터) 루프에 적합
for (int i = 0; i < 5; i++)   // 초기화; 검사; 갱신 한 줄
    cout << i << " ";
```
- `for`는 세 요소를 머리에 모아 두어 누락을 줄임 → 카운터 제어에 권장

## 6.3 사후검사 루프 — do-while
검사를 **본체 실행 후**에 한다 → 본체가 **최소 1회** 실행됨.
```cpp
int input;
do {
    cout << "양수 입력: ";
    cin >> input;
} while (input <= 0);   // 조건 거짓될 때까지 다시
```
- 메뉴, 입력 검증처럼 "일단 한 번은 해야 하는" 작업에 적합

## 6.4 카운터 제어 vs 사건 제어
- **카운터 제어(counter-controlled)**: 반복 횟수를 미리 안다 → `for`
  ```cpp
  for (int i = 0; i < n; i++) sum += i;
  ```
- **사건 제어(event-controlled)**: 횟수를 모르고 어떤 사건이 멈춤을 결정 → `while`
  - **보초값(sentinel)**: 데이터 끝을 알리는 특수 값
  ```cpp
  cin >> x;
  while (x != -1) {        // -1이 보초값
      sum += x;
      cin >> x;
  }
  ```
  - **EOF 제어**: `while (cin >> x) { ... }` — 입력 실패 시 종료

## 6.5 중첩 루프
루프 안의 루프 — 안쪽이 바깥쪽 한 번마다 전부 돈다.
```cpp
for (int i = 1; i <= 3; i++) {       // 바깥: 행
    for (int j = 1; j <= 4; j++)     // 안쪽: 열
        cout << i * j << '\t';
    cout << endl;
}
```
- 총 본체 실행 = 바깥 × 안쪽 → 성능에 직접 영향
- 안쪽 루프의 제어 변수는 매 외부 반복마다 다시 초기화해야 함

## 6.6 루프 불변식과 흐름 제어
- **루프 불변식(invariant)** 직관: 매 반복 전후로 항상 참인 성질 (예: "지금까지의 합은 `sum`에 들어 있다") → 정확성 검증의 근거
- **break**: 가장 안쪽 루프를 즉시 탈출
- **continue**: 남은 본체를 건너뛰고 다음 반복으로
```cpp
for (int i = 0; i < 10; i++) {
    if (i == 5) break;       // 5에서 멈춤
    if (i % 2 == 0) continue;// 짝수 건너뜀
    cout << i << " ";        // 1 3 출력
}
```
- 구조적 관점: `break`/`continue`는 흐름을 끊으므로 **남용하지 말 것** — 가능하면 종료 조건으로 표현

## 자주 하는 실수
- 갱신문 누락 → 무한 루프 (`while (n <= 5)`인데 `n++` 빼먹기)
- `for (...)` 뒤에 잘못 붙인 `;` → 본체가 빈 문장이 됨: `for (i=0;i<5;i++);`
- 경계 조건(off-by-one): `<`와 `<=` 혼동으로 한 번 더/덜 반복
- 사건 제어인데 카운터(`for`)로 억지로 만듦 → 보초값/EOF 처리 누락
- 중첩 루프에서 안쪽 제어 변수 재초기화를 잊음

## 연습문제
1. 입력한 정수의 각 자릿수 합을 구하라(`while` + `% 10`, `/ 10`).
2. 2부터 n까지의 소수를 모두 출력하라(중첩 루프).
3. 사용자가 음수를 넣을 때까지 양수만 누적 합산하라(`do-while`).
> 힌트: 1번은 10으로 나눠가며 나머지를 더하고 몫으로 갱신한다.
