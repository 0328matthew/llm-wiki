# 🏛️ 나만의 정치사상 토론 상대 — 사용법

> `65-Politics/`는 백과사전이 아니라 **LLM을 정치 이념 토론 상대로 쓰기 위한** 섹션이다.
> 시작점: [[Politics-MOC]]

## 구조
- `65-Politics/Ideologies/` — 20개 핵심 이념(-ism) 노트
- 각 노트: `한 줄 요약 → 핵심 주장 → 인간관·국가관 → 논증 → 대표 사상가 → 하위 분파 → 현실 사례 → 비판 → 토론 프롬프트`
- **하위 분파**: 각 노트의 `## 하위 분파` 섹션에 placeholder 링크를 두었다. 클릭하면 `ideology` 템플릿으로 새 노트가 생겨 점점 세분화할 수 있다.

## 5가지 토론 모드
1. **패널 토론** — 한 사안에 여러 이념을 세워 논쟁시키기
   - "최저임금 인상을 [[자유지상주의]]·[[사회민주주의]]·[[보수주의]] 패널로 토론해줘."
2. **스틸맨 + 해체** — 한 이념을 가장 강하게 변호한 뒤 약점 공략
   - "[[신자유주의]]를 최대한 강하게 변호하고, 그다음 가장 치명적인 반론을 제시해줘."
3. **스펙트럼 매핑** — 내 입장이 어디쯤인지 좌표 찍기
   - "내 생각: '복지는 늘리되 시장은 자유롭게'. 이건 어떤 이념에 가깝고 어떤 긴장이 있나?"
4. **개념 검사** — 특정 정책을 한 이념의 잣대로 평가
   - "이 정책이 [[공화주의]]가 말하는 '비지배 자유'를 늘리나 줄이나?"
5. **계보 추적** — 이념의 철학적 뿌리로 거슬러 올라가기
   - "[[자유주의]]가 [[로크]]·[[밀 (J.S. Mill)]]·[[롤스]]를 거치며 어떻게 변했나?"

## 주의
- 이 노트들은 **사상의 논리 구조**를 정리한 것이지, 특정 정당·인물 지지가 아니다.
- 각 이념은 "가장 설득력 있는 버전(스틸맨)"으로 서술하고 `비판` 섹션에서 균형을 잡는다.
