## 핵심 개념
- 상태량과 경로량을 구별하고 계·주위·경계 및 평형 상태를 정리한다.
- 열기관의 열효율은 $\eta=1-Q_L/Q_H$이며 Carnot 기관은 $\eta_{rev}=1-T_L/T_H$이다.

### 6쪽

Thermodynamic state
Thermodynamics deals with equilibrium states.
Equilibrium: A state of balance.
In an equilibrium state there are no unbalanced potentials (or driving f
orces) within the system.
Thermal equilibrium: If the temperature is the same throughout the e
ntire system.
Mechanical equilibrium: If there is no change in pressure at any poin
t of the system with time.
Phase equilibrium: If a system involves two phases and when the m
ass of each phase reaches an equilibrium level and stays there.
Chemical equilibrium: If the chemical composition of a system does
not change with time, that is, no chemical reactions occur.

electric wire crossing the system

are positive; heat transfer from a system
and work done on a system are

### 32쪽

The Carnot cycle – Ideal case for maximum efficiency
Carnot cycle is the most efficient, reversible cycle that can operate between
two reservoirs that have different temperature (TH and TL).
1 → 2 : Reversible isothermal expansion process
QH is transferred from hot reservoir (TH + dT) to the
system (TH constant)
QH
2 → 3 : Reversible adiabatic expansion process
Working fluid: TH -> TL with work generated
QL
3 → 4 : Reversible isothermal compression process
QL is rejected from the system (TL constant) to cold
reservoir (TL - dT).
4 → 1 : Reversible adiabatic compression process
Working fluid: TL -> TH with work required
