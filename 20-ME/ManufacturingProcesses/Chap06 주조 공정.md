## 한 줄 요약
5장의 원리를 실제 공정으로 옮기면 모든 선택이 **주형을 한 번 쓰고 버릴 것인가, 여러 번 쓸 것인가**에서 갈린다. 소모성 주형은 **형상 자유도**를, 영구 주형은 **생산성과 정밀도**를 얻는다. 여기에 용해로·후처리·결함·주조용 금속·설계 지침이 붙는다.

## 6-1 두 범주 (이 장의 목차)

| | 소모성 주형 expendable | 영구 주형 permanent |
|---|---|---|
| 주형 | 부품을 꺼내려면 **희생** | 금속 주형을 여러 번 사용 |
| 장점 | 더 복잡한 형상 가능 | 높은 생산 속도 |
| 단점 | 생산 속도가 **주형 제작 시간**에 좌우 | 주형을 열어야 하므로 형상 제약 |
| 공정 | 사형 · 셸 몰딩 · 소실 폼 · 인베스트먼트 · 석고/세라믹 | 기본 영구 주형 · 다이캐스팅 · 스퀴즈/반응고 · 원심 주조 |

## 6-2 사형 주조 (Sand Casting)

- **가장 널리 쓰이는 주조 공정** — 전체 주조 생산량의 대부분
- 강·니켈·티타늄처럼 **융점이 높은 금속**을 포함해 거의 모든 합금 가능
- 크기는 소형 ~ 초대형, 수량은 1개 ~ 수백만 개

**공정 순서**
```
패턴 제작 ─┐
코어 제작 ─┼→ 주형 제작(조형) → 주입 → 응고 → 파형(주형 파괴) → 청정·검사 → 트리밍 → (열처리)
용해 ─────┘
```
- 주형은 **부품마다 새로** 만들어야 한다 — 패턴 제작과 조형이 공정의 절반

### 패턴 (Pattern)
- 부품의 실물 크기 모형 — **수축과 다듬질 여유**를 감안해 조금 크게
- 재료: **목재**(가공이 쉬워 가장 흔하지만 휜다) · **금속**(비싸지만 오래 간다) · **플라스틱**(절충)

| 종류 | 설명 |
|---|---|
| (a) 일체형 solid | 한 덩어리 |
| (b) 분할형 split | **두 조각**으로 된 패턴 |
| (c) 매치 플레이트 match-plate | 분할 패턴 두 조각을 **판의 양면에 붙인** 것 |
| (d) 상·하형 분리형 cope and drag | 상형용·하형용을 각각 별도 판에 |

### 코어와 체이플릿
- **코어(core)** = 부품 **내부 표면**의 실물 모형. 주입 전에 공동 안에 넣는다. 용탕이 공동과 코어 사이로 흘러 굳으며 외부·내부 표면이 동시에 만들어진다
- **체이플릿(chaplet)** = 주입 중 코어가 움직이지 않도록 받치는 **금속 지지물**
  - 체이플릿은 **주물 안에 남는다** → 주물과 같거나 **융점이 높은 금속**으로 만들어 녹아 붙게 한다

### 주형이 갖춰야 할 다섯 성질

| 성질 | 내용 |
|---|---|
| **강도** strength | 형상을 유지하고 용탕의 흐름에 침식되지 않을 것 |
| **통기성** permeability | 뜨거운 공기와 가스가 모래의 빈틈으로 빠져나갈 수 있을 것 |
| **열안정성** thermal stability | 용탕과 닿는 순간 갈라지거나 휘지 않을 것 |
| **붕괴성** collapsibility | 주물이 수축할 때 주형이 **양보**해 주물이 갈라지지 않게 할 것 |
| **재사용성** reusability | 깨뜨린 주형의 모래를 다시 쓸 수 있을 것 |

> 서로 부딪치는 요구: 강도 ↑를 위해 곱고 불규칙한 입자를 쓰면 **통기성 ↓**.

### 주물사와 결합제
- **주물사** = 실리카($\mathrm{SiO_2}$) 또는 실리카 + 다른 광물의 혼합 — **내화 성질**이 좋다
- **입도** — 작으면 표면이 매끄럽고, 크면 통기성이 좋다
- **입자 형상** — 불규칙하면 서로 맞물려 튼튼하지만 통기성은 떨어진다
- 결합제: **물 + 점토** — 대표 배합 **모래 90 % · 물 3 % · 점토 7 %**
  - 그 밖에 유기 수지(페놀 수지), 무기 결합제(규산나트륨, 인산염), 각종 첨가제

> **무엇이든 통기성과 맞바꾼다** — 표면 품질 ↔ 통기성, 강도 ↔ 통기성.

### 사형 주형의 종류 — "습기를 얼마나 뺄 것인가"

| 종류 | 내용 |
|---|---|
| **생형** green-sand | 모래 + 점토 + **물**. "green"은 주입 시점에 습기를 머금고 있다는 뜻 — 가장 널리 쓰임 |
| **건조형** dry-sand | 점토 대신 **유기 결합제**를 쓰고 주형을 **구워** 강도를 높임 |
| **표면 건조형** skin-dried | 생형의 공동 표면만 **10 ~ 25 mm 깊이**까지 토치·가열 램프로 말린 것 |

> 습기를 빼면 강도·정밀도가 오르지만 시간과 비용이 든다.

## 6-3 그 밖의 소모성 주형 공정

### 셸 몰딩 (Shell Molding)
**가열한 금속 패턴 + 열경화성 수지 혼합 모래**로 얇은 '껍질' 주형을 만든다.

1. 가열한 금속 패턴을 수지 + 모래가 든 상자 위에 덮음
2. 뒤집어 모래를 부으면 **표면에서 일부 경화**
3. 되돌려 굳지 않은 모래를 털어냄 — **얇은 셸만 남음**
4. 오븐에서 수 분 가열해 경화 완료
5. 셸 주형을 패턴에서 떼어냄
6. 두 셸을 합쳐 상자 안에서 모래·금속 숏으로 받치고 주입
7. 스프루를 제거해 완성

| 장점 | 단점 |
|---|---|
| 공동 표면이 매끄러워 용탕이 잘 흐르고 **표면 품질**이 좋다 | **금속 패턴이 비싸다** |
| 치수 정확도가 좋다 | 소량 생산에는 정당화하기 어렵다 |
| 주형의 붕괴성이 좋아 주물 균열이 적다 | |
| 대량 생산용으로 기계화 가능 | |

### 소실 폼 (Expanded Polystyrene) — 로스트 폼
1. **폴리스티렌 폼 패턴**에 내화 도료를 입힘
2. 상자 안에서 패턴 둘레에 모래를 다져 넣음
3. 주입하면 **폼이 기화**하고 그 자리를 용탕이 채움

- 다른 이름: lost pattern, evaporative-foam, full-mold 공정
- 폼 패턴에 **스프루·라이저·게이팅·코어까지 함께** 만들어 둔다
- **패턴을 빼내지 않으므로 상·하형으로 열 필요가 없다**
- 장점: 조형이 단순·빠름 / 단점: **주물 하나마다 새 패턴** — 경제성은 패턴 제작비에 달림
- 용도: 자동차 엔진 주물의 대량 생산(폼 성형과 주조가 자동화 라인으로 연결)

> '패턴을 빼지 않는다'는 한 가지 발상이 **장점과 단점을 동시에** 만든다.

### 인베스트먼트 주조 (Investment Casting, 로스트 왁스)
1. **왁스 패턴** 제작 → 스프루에 붙여 **패턴 트리**
2. 트리에 내화 재료를 얇게 코팅
3. 충분히 덮어 단단한 주형 완성 (*investment* = '완전히 덮다')
4. 거꾸로 놓고 가열 — **왁스가 녹아 흘러나옴(탈랍)**, 회수해 재사용
5. 주형을 고온 예열 후 주입·응고
6. 주형을 깨고 주물을 스프루에서 분리

| 장점 | 단점 |
|---|---|
| **매우 복잡하고 정교한 부품** 가능 | 공정 단계가 많다 |
| 치수 관리가 정밀하고 표면이 좋다 | 상대적으로 **비싼 공정** |
| 왁스는 회수해 재사용 | |
| **네트 셰이프** — 보통 추가 절삭 불필요 | |

- 대표 용도: 항공용 터빈 부품 — 108개 날개 일체형 압축기 스테이터처럼 절삭으로는 만들기 어려운 형상

### 석고 주형 · 세라믹 주형

| | 주형 재료 | 특징 |
|---|---|---|
| 석고 주형 plaster | 석고 $\mathrm{CaSO_4\cdot 2H_2O}$ + 물 | 혼합물이 패턴 둘레로 잘 흘러 **미세한 디테일**과 좋은 표면. 물과 오래 닿아 **목재 패턴은 쓰지 않는다** |
| 세라믹 주형 ceramic | **내화 세라믹** | 더 높은 온도를 견뎌 **강·주철 등 고온 합금**도 주조 가능 |

- 석고 주형의 한계: 수분을 빼려면 구워야 하는데 **수분이 남으면 결함**, 과하게 구우면 **강도 상실**. 고온을 못 견뎌 **융점이 낮은 합금 전용** → 이 한계를 푼 것이 세라믹 주형
- 두 공정의 차이는 결국 **주형 재료가 견디는 온도** 하나

## 6-4 영구 주형 공정

### 기본 영구 주형 주조
- 쉽고 정밀하게 열고 닫히도록 설계된 **두 쪽 금속 주형**을 쓴다. 저융점 합금용 주형은 보통 강·주철
- 순서: ① 주형 예열 + 윤활·방열 도료 분무 → ② (필요하면) 코어를 넣고 주형을 닫음 → ③ **중력으로** 용탕을 부어 응고

| 장점 | 한계 |
|---|---|
| 치수 관리·표면 품질이 좋다 | 일반적으로 **융점이 낮은 금속**에 한정 |
| 빠른 냉각 → **미세 조직 → 더 강한 주물** | 주형을 열어야 하므로 형상이 단순해야 함 |
| | **주형 비용이 비싸다** |

- 주형이 비싸므로 **대량 생산**에 적합, 자동화하기 좋다
- 부품: 자동차 피스톤, 펌프 몸체, 항공기·미사일용 주물
- 금속: 알루미늄, 마그네슘, 구리계 합금, 주철 — **강은 부적합**(주입 온도가 너무 높다)

### 다이캐스팅 (Die Casting)
- 용탕을 **고압으로 주형 공동에 사출**하는 영구 주형 공정. 응고 중에도 압력을 유지하다가 주형을 열어 부품을 꺼낸다
- 주형을 **다이(die)** 라 부르기에 die casting. **고압으로 밀어 넣는다**는 점이 다른 영구 주형 공정과의 결정적 차이
- 기계는 두 쪽 주형을 정확히 닫고, 금속이 밀려 들어오는 동안 **형체력으로 닫힌 상태를 유지**해야 한다 — 기계가 큰 이유

| | 핫 챔버 hot-chamber | 콜드 챔버 cold-chamber |
|---|---|---|
| 용해 | 금속이 **기계 안 용기**에서 녹는다 | **외부 용해 용기**에서 떠 넣는다 |
| 동작 | 플런저 상승 → 용탕 유입 → 압입 → 후퇴·개방·이젝트 | 램 후퇴 상태로 주입 → 램이 압입 → 후퇴·개방·이젝트 |
| 속도 | **매우 빠름 — 시간당 500개도 드물지 않다** | 붓는 단계 때문에 **핫 챔버보다 느리다** |
| 금속 | 기계 부품을 침식하지 않는 **저융점** — Zn · Sn · Pb · Mg | **Al · 황동 · Mg** 합금 |

- 다이 재료: 공구강·금형강·마레이징강 (강·주철용은 텅스텐·몰리브덴)
- 다이가 열릴 때 부품을 밀어내는 **이젝터 핀**이 필요하고, 공동 표면에는 **윤활제**를 분무
- **플래시(flash)** = 분할선 틈, 코어·이젝터 핀 주변 틈으로 용탕이 밀려 들어가 생기는 얇은 지느러미 — 고압 공정의 필연적 부산물, 후처리에서 제거

| 장점 | 단점 |
|---|---|
| 대량 생산에 경제적 | 일반적으로 융점이 낮은 금속에 한정 |
| 정확도와 표면 품질이 좋다 | 다이에서 빼낼 수 있는 형상이어야 함 |
| **얇은 단면** 가능 | |
| 빠른 냉각 → 미세 조직 → 높은 강도 | |

### 스퀴즈 주조 · 반응고 주조
공통점은 **완전한 액체가 아닌 상태로 성형한다**는 것.

- **스퀴즈 주조(squeeze casting)** = 주조 + 단조의 결합
  - 예열한 하형에 용탕을 붓고, **응고가 시작된 뒤** 상형을 닫아 공동을 만든다 (보통의 폐쇄 주형은 용탕을 넣기 **전에** 다이를 닫는다)
  - 일반 단조보다 압력이 낮고 더 미세한 표면 디테일
- **반응고 주조(semi-solid metal casting)** = 리퀴더스와 솔리더스 **사이** 온도에서 수행하는 네트 셰이프·니어 네트 셰이프 공정군
  - 합금이 고체·액체가 섞인 **머시(mushy) 상태**로 주조된다
  - 잘 흐르려면 고체가 **둥근 알갱이**로 떠 있어야 하므로, **저어 주어 수지상정(dendrite) 생성을 막는다**
  - 장점: 복잡한 형상 · 얇은 벽 · 좁은 공차 / 기공이 적어 강도가 높다

### 원심 주조 (Centrifugal Casting)
- 주형을 고속 회전시켜 **원심력**으로 용탕을 다이 공동의 바깥쪽에 분포시키는 공정군
- 종류: **진원심** true centrifugal · **반원심** semicentrifugal · **원심 분리** centrifuge casting
- **진원심 주조** — 회전하는 주형에 용탕을 부어 **관 모양 부품**(파이프, 튜브, 부싱, 링)을 만든다
  - 바깥 모양은 원형·팔각형 등 자유롭지만, 안쪽은 방사 대칭인 힘 때문에 (이론상) **완전한 원**이 된다
  - **코어 없이 구멍이 생긴다**는 것이 이 공정의 매력 — 수도관·주철관 제조에 널리 쓰임

## 6-5 주조 현장 (Foundry)

### 용해로

| 용해로 | 특징 | 주 대상 |
|---|---|---|
| **큐폴라** cupola | 바닥 근처에 출탕구가 있는 수직 원통형. 장입물(철·코크스·용제·합금 원소)을 높이의 절반 아래로 투입 | **주철** — 주철 생산량의 대부분 |
| **직접 연소식** direct fuel-fired | 작은 개방 노상 + 측면 천연가스 버너. 지붕이 불꽃을 장입물 쪽으로 반사 | 구리계 합금, 알루미늄 등 **비철** |
| **도가니** crucible | 금속이 **연소 가스와 직접 닿지 않게** 녹임(간접 연소식). (a) 들어내는 (b) 고정식 (c) 기울이는 방식 | 청동·황동·아연·알루미늄 |
| **전기 아크로** | 아크의 열로 장입물 용해. 전력 소비가 크지만 용해 능력을 크게 설계 가능 | 주로 **강** |
| **유도로** induction | 코일의 교류 자기장이 유도 전류를 일으켜 가열. **전자기 교반** + 금속이 발열체와 닿지 않아 **고품질·고순도** | 강·주철·알루미늄 |

> 선택 기준은 **어떤 금속을, 얼마나, 얼마나 깨끗하게**.

### 레이들과 응고 후 공정
- **레이들(ladle)** — 용해로에서 주형까지 용탕을 옮기는 도구 (크레인 레이들, 2인용 레이들 등). 크기와 취급 방식이 주물 규모를 결정
- **트리밍** — 스프루·러너·라이저·분할선 플래시·지느러미·체이플릿 등 여분 금속 제거
  - 취성 합금이나 단면이 작으면 때려서 떼고, 아니면 해머·전단·톱·연삭 휠·토치 절단
  - 잘라 낸 라이저는 **다시 녹여 쓴다**
- **코어 제거** — 결합제가 삭으면서 대개 저절로 빠지거나 흔들어 뺀다. 드물게 화학적으로 녹이고, 고체 코어는 때리거나 눌러 뺀다
- **표면 청정·검사** — 텀블링·숏 블라스팅·와이어 브러싱·버핑·산세. **사형 주조에서 특히 중요**하고 영구 주형에서는 생략되기도 한다
- **열처리** — 이후 절삭을 쉽게 하거나 사용 목적에 맞는 성질을 끌어내기 위해

## 6-6 주조 품질 — 결함

### 모든 공정에 공통인 결함

| 결함 | 내용 |
|---|---|
| **미스런** misrun | 공동을 다 채우기 전에 굳어 버림 |
| **콜드 셧** cold shut | 두 흐름이 만났지만 먼저 굳어 **융합되지 않음** |
| **콜드 숏** cold shot | 주입 중 튄 금속이 알갱이로 굳어 주물에 갇힘 |
| **수축 공동** shrinkage cavity | 마지막에 굳는 부위에 용탕이 부족해 생기는 함몰·내부 공동 |

> 앞의 셋은 **용탕이 제때 못 갔거나 흐름이 나빴을 때**(주입 온도·속도·난류), 넷째는 **수축을 보충하지 못했을 때**(라이저·방향성 응고) 생긴다 — **원인이 곧 5장의 대책**이다.

### 사형 주조 고유의 결함

| 결함 | 내용 |
|---|---|
| **샌드 블로** sand blow | 주입 중 주형 가스가 방출되어 생긴 풍선 모양 공동 |
| **핀홀** pin holes | 표면이나 바로 아래의 다수의 작은 가스 공동 |
| **침투** penetration | 유동성이 지나쳐 용탕이 모래 사이로 스며듦 |
| **주형 어긋남** mold shift | 상형과 하형이 옆으로 밀려 분할선에 단이 생김 |

- 앞의 셋은 **모래·가스(통기성!)**, 넷째는 **조형 작업**의 문제
- 그 밖에 **미세 기공**, **열간 균열(hot tearing)** — 응고 초기 수축에 주형이 양보하지 않아 생기는 균열

### 검사
- **육안 검사** — 미스런·콜드 셧 같은 눈에 보이는 결함과 심한 표면 흠
- **치수 측정** — 공차 만족 여부
- **재질 시험** — 금속·화학·물리 시험으로 **주조 금속 자체**의 품질 확인

## 6-7 주조용 금속
상업용 주물은 대부분 **순금속이 아니라 합금** — 주조가 쉽고 제품 성질도 더 좋다.

### 철계

| | 내용 |
|---|---|
| **주철** | **모든 주조 합금 중 가장 중요** — 생산 톤수가 다른 모든 금속을 합친 것보다 몇 배 많다. 회주철·구상흑연주철·백주철·가단주철·합금 주철. 주입 온도 **약 1400 °C** |
| **강** | 기계적 성질은 매력적이지만 주조가 어렵다 — ① 주입 온도 **약 1650 °C**로 높고 ② 그 온도에서 **쉽게 산화**되어 공기 차단 필요 ③ 용융 강은 **유동성이 나쁘다** |

> 강의 이 세 가지 어려움이 곧 "왜 영구 주형에 강을 못 쓰나"의 답.

### 비철

| 금속 | 특징 |
|---|---|
| **알루미늄** | 주조성이 매우 좋다. 순 Al $T_m$ = **660 °C**. 가볍고, 열처리로 강도 조절, 절삭도 쉬움 |
| **구리 합금** | 청동·황동·알루미늄 청동. 내식성·외관·베어링 성질. 한계는 **높은 가격**. 배관 부속, 선박 프로펠러, 펌프 부품, 장식품 |
| **아연 합금** | 주조성이 매우 좋아 **다이캐스팅**에 널리 쓰임. 순 Zn $T_m$ = **419 °C**, 유동성 좋음. 다만 **크리프 강도가 낮다** |

> 셋의 공통점은 **낮은 융점** — 그래서 영구 주형·다이캐스팅의 주력 재료가 된다. 3장의 용융 특성이 공정 선택을 정하는 실제 사례.

## 6-8 제품 설계 지침

### 형상과 모서리
- **형상의 단순함** — 설계를 단순화하면 주형 제작이 쉬워지고, **코어의 필요가 줄고**, 주물의 강도가 좋아진다
- **모서리** — 날카로운 모서리·각은 **응력 집중** → **열간 균열(hot tearing)** 과 크랙
  - 안쪽 모서리에는 넉넉한 **필릿**, 날카로운 바깥 모서리는 뭉툭하게
  - 주형이 양보하지 못하는 상태에서 주물이 수축하면 모서리에 응력이 집중된다 — 5장의 **붕괴성·방향성 응고**와 같은 문제

### 구배 · 공차 · 다듬질 여유
- **구배(draft)** — 소모성 주형에서는 **패턴**을 빼기 위해, 영구 주형에서는 **부품**을 빼기 위해 준다

| 공정 | 구배 |
|---|---|
| 사형 주조 | 약 **1°** |
| 영구 주형 공정 | **2 ~ 3°** |
| 고체 코어 | 비슷한 테이퍼 |

- **치수 공차와 표면 거칠기** — 공정에 따라 크게 다르다
  - 나쁨: **사형 주조** / 좋음: **다이캐스팅 · 인베스트먼트**
- **다듬질 여유(machining allowance)** — 거의 모든 사형 주물은 요구 치수를 맞추기 위해 절삭이 필요하므로, 절삭할 면에 **여분의 살**을 남겨 둔다

## 자주 하는 실수
- 분할형과 매치 플레이트를 혼동 → 분할형은 **두 조각 패턴**, 매치 플레이트는 그 두 조각을 **판 양면에 붙인 것**
- 체이플릿을 주조 후 제거한다고 생각 → **주물 안에 남는다**(그래서 융점이 같거나 높은 금속)
- 핫/콜드 챔버의 속도 비교를 뒤집음 → **핫 챔버가 빠르다**(콜드는 떠 넣는 단계가 추가)
- 다이캐스팅에 강을 쓸 수 있다고 봄 → 저융점 금속 전용, 강은 주입 온도가 너무 높다
- 주형의 다섯 성질에서 **붕괴성**을 빠뜨림 → 주물 수축 때 주형이 양보해야 주물이 갈라지지 않는다
- 통기성을 무시하고 입자만 곱게 → **샌드 블로·핀홀**의 원인
- 소실 폼이 "패턴을 재사용한다"고 오해 → 폼은 기화되므로 **주물마다 새 패턴**

## 학습 확인
- 분할형과 매치 플레이트의 차이, 체이플릿이란? → 두 조각 패턴 vs 판 양면에 붙인 것 / 코어를 붙드는 금속 지지물(주물에 남음)
- 사형 주형의 품질을 결정하는 성질 다섯은? → 강도 · 통기성 · 열안정성 · 붕괴성 · 재사용성
- 핫/콜드 챔버 중 빠른 쪽은? 플래시란? → **핫 챔버** / 분할선·코어·이젝터 핀 틈으로 밀려 나와 생기는 얇은 금속
- 흔한 일반 결함 세 가지는? → 미스런 · 콜드 셧 · 콜드 숏 (그 밖에 수축 공동, 미세 기공, 열간 균열)
