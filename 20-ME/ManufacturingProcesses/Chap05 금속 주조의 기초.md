## 한 줄 요약
주조는 **① 녹이고 ② 붓고 ③ 굳히는** 세 단계지만, 이 장의 내용은 전부 **③에서 생기는 문제(수축·결함)를 ①·②에서 미리 막는 이야기**다. 핵심 도구는 **Chvorinov 법칙 $T_{TS} = C_m (V/A)^n$** — 응고 시간을 재는 식이자 **라이저를 어떻게 생기게 할지 정하는 설계식**.

---

## 5-1 주조 개요

### 응고 공정과 주조의 정의
- **응고 공정(solidification processes)** = 출발 재료가 액체이거나 매우 소성이 큰 상태이고, 그 재료가 굳으면서 부품이 만들어지는 공정

| 재료 | 공정 |
|---|---|
| 금속 | **주조** (5·6장) |
| 세라믹 — 유리 | 유리 성형 |
| 고분자·PMC | 플라스틱 성형 |

- **주조(casting)** = 용융 금속이 중력이나 다른 힘으로 **주형(mold)** 에 흘러들어가 **공동(cavity)** 의 모양대로 굳는 공정. 그렇게 만든 부품도 casting이라 부른다

### 세 단계
1. **녹인다** — 용해로에서 주입 온도까지 가열 (§5-4)
2. **붓는다** — 게이팅 시스템을 지나 공동을 채움 (§5-3)
3. **굳힌다** — 응고·냉각하며 수축 → **여기서 결함이 생긴다** (§5-6)

### 장점과 단점

| 장점 | 단점 |
|---|---|
| **복잡한 형상** — 외부·내부 모두 | 기계적 성질의 한계(공정에 따라 다름) |
| 일부는 **네트 셰이프**, 일부는 니어 네트 셰이프 | 공정에 따라 치수 정확도·표면 거칠기가 나쁨(예: 사형 주조) |
| 매우 큰 부품도 가능 | 뜨거운 용융 금속으로 인한 작업자 안전 문제 |
| 일부는 대량 생산에 적합 | 환경 문제 |
| 녹일 수 있는 금속이면 거의 모두 적용 | |

- 크기 범위가 매우 넓다: 엔진 블록·헤드, 기계 프레임, 철도 차륜, 교회 종, 대형 조각상 ↔ 치과용 크라운, 장신구, 프라이팬

## 5-2 주형 (The Mold)

- 주조는 보통 **주조 공장(foundry)** 에서 이루어진다 — 주형 제작, 용해·취급, 주조, 주물 청정을 갖춘 공장
- 주형은 부품 모양을 결정하는 **공동(cavity)** 을 가지며, **수축을 감안해 약간 크게** 만든다
- 주형 재료: 모래, 석고, 세라믹, 금속

| | 구조 |
|---|---|
| **개방형** open mold | 위가 트인 그릇 모양 — 윗면이 평평해야 한다(실습·시연용) |
| **폐쇄형** closed mold | 공동이 완전히 둘러싸여 있어 바깥에서 **게이팅 시스템**으로 금속을 보낸다(실제 부품 대부분) |

### 소모성 주형 vs 영구 주형 — 6장 전체의 목차

| | 소모성 주형 expendable | 영구 주형 permanent |
|---|---|---|
| 주형 | 주물 하나당 하나 — 깨뜨려야 꺼낸다 | 같은 주형을 여러 번 사용 |
| 재료 | 모래·석고 + **결합제(binder)** | 금속(드물게 세라믹 내화물) |
| 형상 | **더 복잡한 형상 가능** | 주형을 열어야 하므로 제약 |
| 생산성 | 주조 자체보다 **주형 제작 시간**에 묶임 | 대량 생산에서 경제적 |
| 조직 | — | **빠른 냉각 → 미세 조직 → 강한 주물** |
| 6장의 공정 | 사형·셸·소실 폼·인베스트먼트 | 다이캐스팅·원심 주조 |

> 맞바꿈의 핵심: **형상 자유도 ↔ 생산성**

### 사형 주형의 구조와 용어
- 주형은 두 쪽 — **상형(cope)** 과 **하형(drag)**
- 두 쪽은 **주형틀(flask)** 에 담기고, 맞닿는 면이 **분할선(parting line)**
- 공동 위쪽에 금속을 보충하는 **라이저(riser, 압탕)**, 바깥에서 공동까지 흐르는 **게이팅 시스템**

### 패턴과 코어

| | 역할 |
|---|---|
| **패턴 pattern** | 부품 모양의 모형. 둘레에 모래를 다지고 빼내면 남은 공동이 **외부 형상**. 수축을 감안해 약간 크게 |
| **코어 core** | 공동 안에 미리 넣어 두는 모형. 금속이 코어 둘레로 굳으며 **내부 형상**이 생긴다. 사형에서는 코어도 보통 모래 |

> 주형을 상형·하형 두 쪽으로 나누는 이유 — **패턴을 빼내야 공동이 남기 때문**. 한 덩어리 주형에서는 패턴을 꺼낼 수 없고, 코어도 넣을 수 없다. 같은 이유로 영구 주형·다이캐스팅은 형상에 제약이 생긴다.

### 게이팅 시스템과 라이저
- **게이팅 시스템** = 주형 바깥에서 공동까지 용탕이 흐르는 통로
  - **주입컵(pouring cup)** → **다운스프루(downsprue)** → **러너(runner)** → 게이트 → 공동
  - 주입컵은 금속이 들어갈 때 **튀김과 난류를 줄인다**
- **라이저(riser)** = 주형 안의 **금속 저장고**. 응고 중 줄어드는 부피를 보충
  - 제 역할을 하려면 **라이저가 주물보다 나중에 굳어야 한다** → 설계 근거가 Chvorinov 법칙

## 5-3 가열과 주입 (Heating · Pouring)

### 필요한 열 — 세 몫의 합
1. **융점까지** 올리는 열
2. 고체 → 액체 변환의 **융해열(heat of fusion)**
3. **주입 온도까지** 더 올리는 열

- **과열(superheat)** = 주입 온도가 융점보다 높은 만큼의 온도 차. 주입에서 응고까지 빠져나가는 열량을 뜻하기도 한다

### 주입의 세 요인
금속이 굳기 전에 주형 구석구석을 채워야 한다 — 좌우하는 것은 **주입 온도 · 주입 속도 · 난류**.

> **난류**는 ① 굳은 금속 안에 **산화물 생성**을 촉진하고 ② 용탕의 충격으로 **주형을 침식**시킨다.
> 그래서 주입컵과 게이팅으로 흐름을 다스린다.

### 주입 흐름의 기본 관계
$$
v = \sqrt{2gh},\qquad Q = vA,\qquad T_{MF} = \frac{V}{Q}
$$
- $v$ = 다운스프루 바닥에서의 유속(Bernoulli), $h$ = 스프루 높이
- $Q$ = 체적 유량 — 연속식에 따라 흐름 전체에서 일정
- $T_{MF}$ = **주형 충전 시간** = 공동 부피 ÷ 유량
- 스프루 아래로 갈수록 유속이 커지므로, **단면적을 줄여 주지 않으면 공기를 빨아들인다(aspiration)**

## 5-4 응고 (Solidification)

### 순금속
- **융점과 같은 일정한 온도에서 굳는다** → 냉각 곡선에 **평평한 구간**(국부 응고 시간)이 생긴다
- 조직: 주형 벽의 냉각으로 경계면에 얇은 **고체 껍질(skin)** 이 생겨 두꺼워진다
  - 벽 근처는 작고 방향이 무작위인 결정립, 중심을 향해서는 굵은 **주상정(columnar grains)**
- 굳는 속도는 **주형으로의 열전달**과 **금속의 열적 성질**(열전도도·비열, [[Chap03 공업 재료의 성질]])에 달려 있다

### 합금
- 대부분의 합금은 **온도 구간**에 걸쳐 굳는다 — **리퀴더스**에서 시작, **솔리더스**에서 완료
- 고체·액체가 섞인 구간이 있으므로 조직과 성분이 위치에 따라 달라진다 → 주물 중심부에 합금 원소가 몰리는 **편석(segregation)**
- **공정 합금(eutectic alloy)** 은 예외 — 솔리더스 = 리퀴더스여서 순금속처럼 **한 온도**에서 굳는다(그 온도가 공정 온도)

---

## 5-5 응고 시간 — Chvorinov 법칙
$$
\boxed{\;T_{TS} = C_m\left(\frac{V}{A}\right)^{n}\;}\qquad n \approx 2
$$
- $T_{TS}$ = **총 응고 시간**(주입 후 주물이 다 굳는 데 걸리는 시간)
- $V$ = 주물의 부피, $A$ = 주물의 표면적
- $C_m$ = **주형 상수** — 주형 재료 · 주조 금속의 열적 성질 · 융점 대비 주입 온도를 담고 있다
  - 같은 주형 재료·금속·주입 온도로 한 **이전 작업의 실측값**을 쓸 수 있다. **부품 모양이 전혀 달라도 된다**

> **$V/A$ 비가 큰 주물일수록 천천히 굳는다** — 부피는 열을 품고, 표면은 열을 내보내기 때문.

### 라이저 설계로의 연결
- 라이저가 제 역할을 하려면 **라이저의 $T_{TS}$ > 주물의 $T_{TS}$**
- 라이저와 주물의 $C_m$은 같으므로, **라이저의 $V/A$를 더 크게** 설계하면 주물이 먼저 굳는다

## 5-6 수축 (Shrinkage)

### 수축은 세 번 일어난다
1. **액체 수축** — 주입 후 냉각 중 용탕의 높이 감소
2. **응고 수축** — 액체 → 고체 변환. 높이 감소 + **수축 공동(shrinkage cavity)** 생성
3. **고체 열수축** — 고체 상태에서의 부피 추가 감소

- 응고 수축은 거의 모든 금속에서 일어난다 — **고체상이 액체상보다 밀도가 크기** 때문
- **예외: 탄소 함량이 높은 주철** — 응고 마지막 단계의 **흑연화**가 팽창을 일으켜 부피 감소를 상쇄
- (2)의 수축 공동이 바로 **라이저로 막으려는 결함**이다

### 대책 ① 수축 여유
- **수축 여유(pattern shrinkage allowance)** — 패턴 제작자가 응고 수축·열수축을 감안해 주형 공동을 크게 만드는 것
- 주물 치수는 길이로 표시하므로 여유도 **길이 기준**으로 준다 (예: 백주철 2.1 %, 아연 2.6 %)

### 대책 ② 방향성 응고
**방향성 응고(directional solidification)** = 용탕 공급원에서 **먼 곳부터 굳고**, 응고가 **라이저 쪽으로 진행**되게 만드는 것. 그래야 라이저에서 용탕이 계속 흘러들어 수축 공동을 막는다.

1. Chvorinov 법칙으로 **주물 형상·주형 안에서의 자세·라이저 배치**를 설계
2. **$V/A$가 작은 부위를 라이저에서 멀리** 둔다 → 그곳이 먼저 굳고, 나머지로 가는 용탕 길은 열려 있다
3. **냉금(chill)** — 주물 안이나 밖에 두는 열 흡수체로 특정 부위를 빠르게 굳힌다

### 대책 ③ 라이저 설계
- 라이저는 주물에서 잘라 내어 다시 녹여 쓰는 금속 — 공정 단위로 보면 **버리는 금속**
- 따라서 **부피 $V$는 최소**인 것이 좋다
- 그런데 주물보다 늦게 굳어야 하므로 **$V/A$는 최대**로 하는 모양이어야 한다
- 두 요구를 **모양**으로 동시에 만족시키는 것이 라이저 설계 — 같은 부피라면 **표면적이 작을수록 늦게 굳는다**(그래서 라이저는 뭉툭하게)
- 잘라 내는 작업이 6장의 **트리밍(trimming)**

---

## 자주 하는 실수
- Chvorinov 법칙에서 $C_m$을 재료 상수처럼만 취급 → **주형 재료 + 금속 + 주입 온도**의 조합이고, 실측으로 얻는다
- $V/A$를 거꾸로 이해 → **$V/A$가 클수록 늦게 굳는다**
- 라이저를 "그냥 크게 만들면 된다"고 생각 → 부피는 최소, $V/A$는 최대 — **모양**의 문제
- 수축을 응고 수축 하나로만 셈 → **액체 수축 · 응고 수축 · 고체 열수축** 세 번
- 합금도 순금속처럼 한 온도에서 굳는다고 가정 → **리퀴더스 ~ 솔리더스 구간**(단, 공정 합금은 예외)
- 주입 속도를 무작정 높임 → **난류**가 산화물 생성과 주형 침식을 부른다

## 학습 확인
- 개방형과 폐쇄형 주형의 차이는? → 위가 대기에 열린 그릇 모양(윗면 평평) vs 공동이 완전히 둘러싸이고 **게이팅 시스템**으로 연결
- 과열이란? 난류를 피해야 하는 이유는? → 주입 온도 − 융점 / 난류는 **산화물 생성 촉진**과 **주형 침식**
- 합금과 순금속의 응고 차이, 공정 합금이란? → 구간(리퀴더스 → 솔리더스) vs 한 온도 / 솔리더스 = 리퀴더스가 되는 조성
- Chvorinov 법칙과 수축 세 가지는? → $T_{TS} = C_m(V/A)^2$ / 액체·응고·고체 열수축
