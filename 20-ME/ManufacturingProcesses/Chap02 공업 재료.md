## 한 줄 요약
제조 공정은 재료에서 출발한다. **금속 · 세라믹 · 고분자 · 복합재료** 네 재료군의 구조를 알면 "왜 이 부품에 저 공정을 쓰는가"가 설명된다. 금속은 **철계(강·주철)** 와 **비철**로, 세라믹은 **전통·뉴·유리**로, 고분자는 **가교의 정도**(열가소성 → 탄성체 → 열경화성)로, 복합재료는 **기지 재료**(MMC·CMC·PMC)로 나뉜다.

## 2-1 금속과 합금 (Metals and Their Alloys)

### 정의
- **금속(metal)** — 연성(ductility), 가단성(malleability), 광택, 높은 전기·열 전도성을 갖는 재료 범주. 금속 원소와 그 합금을 모두 포함
- **합금(alloy)** — 둘 이상의 원소로 이루어진 금속으로, **그중 하나 이상이 금속 원소**
  - 탄소(비금속)가 들어간 강이 합금인 이유가 바로 이 정의

### 분류
```
금속 Metals
├─ 철계 ferrous ── 강 steel
│                └ 주철 cast iron
└─ 비철 nonferrous ── Al·Mg(경금속) · Cu · Ni · Ti · Zn
```

### 철–탄소 상태도 (Fe–C Phase Diagram)
- 탄소 약 6%까지의 **2원 상태도**. 가로축 탄소 함량이 강과 주철을 나누는 기준
- 상 기호: $L$ 액상 · $\alpha$ 페라이트 · $\gamma$ 오스테나이트 · $\delta$ 델타 페라이트 · $\mathrm{Fe_3C}$ 시멘타이트
- 주요 선: **1130 °C 공정선**, **723 °C 공석선**

### 강 (Steels) — C 0.02 ~ 2.11 %
대부분의 강은 0.05 ~ 1.1 % C. Mn, Cr, Ni, Mo 등을 포함하는 경우가 많다.

| 종류 | 정의 | 특징 |
|---|---|---|
| 탄소강 plain carbon | 탄소가 주 합금 원소, 나머지 소량(Mn ≈ 0.5%) | C↑ → 강도·경도↑, 연성↓. 고탄소강은 열처리로 마르텐사이트 형성 |
| 저합금강 low alloy | 합금 원소 총량 **5 wt% 미만** | 탄소강보다 강도·경도·고온 경도·내마모성·인성 ↑ (대개 열처리 필요) |
| 스테인리스강 stainless | **Cr 15 % 이상** | 표면에 얇고 치밀한 산화막 → 내식성. 강도·연성 조합 우수하나 가공 어렵고 고가 |
| 공구강 tool steel | 대개 고합금강 | 절삭 공구·다이·금형용. 고온 경도·내마모성·충격 인성 |

**AISI-SAE 표기법 `YYXX`**
- 앞 두 자리 `YY` = 강의 종류(합금 원소), 뒤 두 자리 `XX` = **탄소 함량(1/100 %)**
- 예: `1020` = 탄소강 + 0.20 % C · `1080` 고탄소강 · `4140` Cr–Mo 저합금강
- 저합금강 계열: 13XX(Mn), 20XX(Ni), 31XX(Ni-Cr), 40XX(Mo), 41XX(Cr-Mo)

**탄소 함량에 따른 탄소강 분류**

| 구분 | C 함량 | 용도 |
|---|---|---|
| 저탄소강 | < 0.20 % | 자동차 판금, 구조용 강판, 철도 레일 |
| 중탄소강 | 0.20 ~ 0.50 % | 크랭크샤프트 |
| 고탄소강 | > 0.50 % | 스프링, 절삭 공구 |

**스테인리스강의 종류** — 상온에서 지배적인 **상(phase)** 으로 분류. 첫 자리가 유형, 뒤 두 자리가 강종.

| 유형 | 조직 | 대표 조성 |
|---|---|---|
| Type 302 | 오스테나이트계 austenitic | 18 % Cr, 8 % Ni, 2 % Mn, 0.15 % C |
| Type 430 | 페라이트계 ferritic | 17 % Cr, 0 % Ni, 1 % Mn, 0.12 % C |
| Type 440 | 마르텐사이트계 martensitic | 17 % Cr, 0 % Ni, 1 % Mn, **0.65 % C** |

- 300계 = 오스테나이트계(Cr–Ni) — Ni이 $\gamma$ 영역을 넓혀 상온에서도 오스테나이트 유지
- 400계 = 페라이트·마르텐사이트계(Cr) — 마르텐사이트계는 **탄소가 한 자릿수 더 높아** 열처리로 경화

**공구강의 AISI 기호** — 경화 방식·용도로 붙인다.

| 기호 | 종류 | 용도 |
|---|---|---|
| T, M | 고속도 공구강 high speed | 절삭 공구 |
| H | 열간 가공 공구강 hot work | 열간 가공 다이 |
| D | 냉간 가공 공구강 cold work | 냉간 가공 다이 |
| W | 수냉 경화 공구강 | — |
| S | 내충격 공구강 shock resisting | 높은 인성이 필요한 공구 |
| P | 금형강 mold steels | 플라스틱·고무 성형 금형 |

### 주철 (Cast Irons) — C 2.1 ~ 4 %, Si 1 ~ 3 %
- 이 조성 덕분에 **주조용 금속으로 매우 적합**. 전체 톤수는 금속 중 강에 이어 2위
- 종류: 회주철 · **연성주철(구상흑연주철)** · 백주철 · **가단주철** · 합금 주철
  - 연성주철·가단주철은 각각 회주철·백주철과 조성이 비슷하지만 **특수 처리**를 거친 것

**흑연의 형태가 성질을 결정한다**

| | 흑연 형태 | 성질 |
|---|---|---|
| 회주철 gray | 편상 흑연 flake | 끝이 날카로워 **응력 집중** → 인성 낮고 취성. 대신 진동 감쇠·절삭성 우수 |
| 연성주철 ductile | 구상 흑연 nodular | **Mg·Ce 소량 첨가**로 구상화 → 균열 전파 억제 → 연성·인성 확보 |

> Mg는 끓는점(약 1090 °C)이 철 용탕 온도(1400 °C 이상)보다 낮아, 넣는 순간 격렬히 기화·반응한다 — 주조 현장에서 불꽃이 튀는 이유.

### 비철 금속 (Nonferrous Metals)
철을 기반으로 하지 않는 금속·합금. 강만큼 강하지 않아도 **비강도(strength-to-weight ratio)** 나 기계적 성질 외의 특성으로 쓰인다.

| 금속 | 대표 성질 · 실물 예 |
|---|---|
| Al | 성형성(복잡한 단면의 압출재) + 경량 — 프레임·방열판·창틀 |
| Mg | 가장 가벼운 구조 금속 |
| Cu | 낮은 전기 저항 → 도체, 우수한 열 전도 |
| Ni | 고온 특성 — 초합금의 주력 기지 |
| Ti | 내식성·생체 적합성·비강도 — 인공 관절(단조 임플란트) |
| Zn | 용융 아연 도금 — 아연이 먼저 부식되어 강을 보호(표면의 **스팽글** 무늬) |

> 용융 아연 도금: 탈지 → 수세 → 산세 → 플럭스 → 아연 욕 침지 → 검사.
> 전처리가 많은 이유는 **용융 아연이 강 표면과 직접 반응해 합금층을 만들어야** 붙기 때문 — 기름·산화물이 남으면 미도금.

### 초합금 (Superalloys)
- 높은 사용 온도에서의 **강도와 표면 열화 저항**을 만족하도록 설계된 고성능 합금. 셋 이상의 금속을 상당량 포함하는 경우가 많다
- 상온 강도는 평범하지만 **고온 성능이 탁월** — 고온 인장 강도, 고온 경도, **크리프 저항**, 내식성. 작동 온도 보통 **약 1100 °C**
- 용도: 가스 터빈(제트·로켓 엔진), 증기 터빈, 원자력 발전소 — 고온일수록 효율이 좋은 시스템
- 거의 모든 초합금은 **석출 경화(precipitation hardening)** 로 강화

| 기반 | 특징 |
|---|---|
| 철 기반 | 경우에 따라 Fe가 50 % 미만. 합금 원소 Ni, Cr, Co |
| 니켈 기반 | 합금강보다 우수한 고온 강도. 합금 원소 Cr, Co, Fe, Mo, Ti |
| 코발트 기반 | 약 40 % Co, 약 20 % Cr. 합금 원소 Ni, Mo, W |

## 2-2 세라믹 (Ceramics)

### 정의와 성질
- **금속(또는 준금속) + 하나 이상의 비금속**으로 이루어진 무기 화합물
  - 실리카 $\mathrm{SiO_2}$ — 대부분 유리 제품의 주성분
  - 알루미나 $\mathrm{Al_2O_3}$ — 연삭재부터 인공 골까지
  - 수화 알루미늄 규산염 $\mathrm{Al_2Si_2O_5(OH)_4}$ — 대부분 점토 제품의 주성분
- 성질: **높은 경도**, 전기·열 절연성, 화학적 안정성, 높은 융점, **취성(brittle)** — 연성이 거의 없어 가공과 성능 양쪽에서 문제. 일부는 반투명(창유리)

### 세 기본 범주

| 범주 | 원료·구조 | 예 |
|---|---|---|
| 전통 세라믹 | **자연 광물** 규산염·실리카·산화물 기반, 수천 년 역사 | 도자기, 벽돌, 시멘트, 일반 연삭재 |
| 뉴 세라믹 | **합성**, 화학적으로 단순(산화물·탄화물·질화물·붕화물) | 절삭 공구 인서트, 고성능 부품 |
| 유리 | 주로 실리카 기반, **비결정(비정질) 구조** | 창유리, 용기, 실험 기구, 광섬유 |

### 전통 세라믹
- 점토·실리카 같은 광물 규산염 + 알루미나가 주 원료 (수십억 년의 지질 작용으로 형성)
- 제품: 도자기·식기(점토 + 실리카 + 장석) · 벽돌·타일 · **내화물**(알루미나) · **연삭재**(알루미나, 탄화규소)
- 유리도 규산염 세라믹이어서 전통 세라믹에 포함되기도 함

### 뉴 세라믹
- **산화물 세라믹** — 가장 중요한 것은 알루미나 $\mathrm{Al_2O_3}$. 보크사이트에서 **합성 생산**도 한다
  - 입자 크기·불순물 제어, 가공법 개선으로 천연 알루미나보다 강도·인성이 크게 향상
  - 우수한 고온 경도, 낮은 열전도도, 좋은 내식성
  - 용도: 연삭재, 바이오세라믹(인공 골·치아), 전기 절연체, 내화 벽돌, 절삭 공구 인서트, 점화 플러그
  - ※ 알루미나가 '전통'과 '뉴' 양쪽에 들어가는 이유 = 원료 출처가 아니라 **합성·가공 제어 여부**
- **탄화물 carbides** — SiC, **WC**, TiC, TaC, $\mathrm{Cr_3C_2}$
  - WC·TiC·TaC는 단단하고 내마모성이 좋아 절삭 공구에 사용
  - 단, **Co·Ni 같은 금속 결합제와 결합해야** 유용한 고체 제품이 된다 → 초경합금(§2-4)
- **질화물 nitrides** — $\mathrm{Si_3N_4}$, BN, TiN
  - 단단하고 취성, 높은 융점, 보통 전기 절연성(TiN은 예외)
  - $\mathrm{Si_3N_4}$: 가스 터빈·로켓 엔진 부품·용해 도가니 / BN·TiN: 절삭 공구 재료와 코팅

### 유리 (Glass)
- **물질의 상태**로서의 유리 = 고체의 **비정질(amorphous)** 구조. 냉각될 때 결정 구조를 만들 시간이 부족하면 유리 상태가 된다
- **세라믹의 한 종류**로서의 유리 = 결정화 없이 냉각되어 단단해지는 무기·비금속 화합물
- $\mathrm{SiO_2}$가 많은 이유 = **최고의 유리 형성체(glass former)**. 보통 전체 조성의 **50 ~ 75 %**

| 기타 성분 | 기능 |
|---|---|
| $\mathrm{Na_2O}$, CaO | 가열 시 **융제(flux)** — 융해 촉진 |
| $\mathrm{Al_2O_3}$, MgO, $\mathrm{K_2O}$ | 유동성 향상, 화학 저항성(산·염기·물) 향상 |
| PbO | 광학용 **굴절률** 조절 |
| $\mathrm{B_2O_3}$ | 내열·화학 저항 |

- 제품: 창유리 · 용기 · 전구 · 실험 기구 · 유리 섬유(절연재·광섬유) · 광학 유리(렌즈)

> **플로트 유리**: 용융 주석 위에 유리를 띄워 평평한 판을 얻는다. 주석은 유리보다 밀도가 크고 성형 온도에서 액체이며 유리와 섞이지 않는다.
> 서냉(annealing)을 건너뛰면 잔류 응력이 갇혀 절단 시 깨진다.

### 결정화 유리 (Glass-Ceramics)
유리를 **열처리로 다결정 구조로 변환**한 세라믹. 결정상 90 ~ 98 %, 나머지는 유리질.

1. **성형** — 유리 가공의 가열·성형 기술로 제품 형상을 만듦
2. **냉각 → 재가열** — 조밀한 **결정 핵** 형성. 핵 생성제 $\mathrm{TiO_2}$, $\mathrm{P_2O_5}$, $\mathrm{ZrO_2}$
3. **고온 열처리** — 결정상 성장

- 장점: 유리 상태의 가공 효율 + 정밀한 치수 제어 / 높은 강도(유리보다 강함), 기공 없음, 낮은 열팽창, **높은 열충격 저항**
- 결정립이 일반 세라믹보다 훨씬 작아 강하고, 결정 구조 때문에 불투명(회색·흰색)
- 용도: 조리 기구(Corning ware), 열교환기, 미사일 레이돔

## 2-3 고분자 (Polymers)

### 정의와 합성
- **반복 단위(mer)** 가 연결된 긴 사슬 분자. 분자 하나에 수천 ~ 수백만 개의 단위
  - poly(많은) + meros(부분) → polymer
- 대부분 탄소 기반 → 유기 화합물. 공학용은 거의 모두 **합성 고분자**
- **단량체(monomer)** = 에틸렌 $\mathrm{C_2H_4}$ 같은 단순 **불포화** 유기 분자 → 이중 결합이 열리며 사슬(거대 분자)이 된다

### 세 범주와 시장

```
고분자 Polymers
├─ 플라스틱 plastics ── (1) 열가소성 TP  ≈ 70 %
│                     └ (2) 열경화성 TS ┐
└─ 고무 rubbers ────── (3) 탄성체      ┘ 나머지 30 %를 거의 균등 분담(TS가 약간 우세)
```
- 부피 기준 고분자의 연간 사용량은 **금속을 초과**

| 범주 | 예 |
|---|---|
| 열가소성 | PE, PVC, PP, PS, 나일론 |
| 열경화성 | 페놀 수지, 에폭시, 일부 폴리에스터 |
| 탄성체 | 천연고무(가황), 합성고무(톤수는 NR보다 많음) |

**고분자가 중요한 이유**
- 복잡한 형상으로 성형 가능, 보통 후가공 불필요 → **네트 셰이프 가공**에 매우 적합
- 부피 기준 금속과 비용 경쟁력 / 생산 에너지가 적게 듦 / 일부는 투명해 유리와 경쟁

| 일반 성질 | 한계 |
|---|---|
| 낮은 밀도 | 낮은 강도 |
| 일부는 우수한 비강도 | **낮은 탄성 계수(강성)** |
| 높은 내식성 | 사용 온도가 수백 도로 제한 |
| 낮은 전기·열 전도도(절연체) | **점탄성** — 하중 지지 용도의 뚜렷한 한계 |
| | 일부는 햇빛 등 방사선에 열화 |

### 분자 구조 — 분지와 가교

| 구조 | 해당 |
|---|---|
| 선형 linear | 열가소성 |
| 분지 branched | 열가소성 |
| 느슨한 가교 loosely cross-linked | **탄성체** |
| 촘촘한 가교 tightly cross-linked | **열경화성** |

- **분지(branching)** — 곁가지가 분자 간 **얽힘(entanglement)** 을 늘려 고체에서 더 강하게, 액체에서 더 점성이 높게
- **가교(cross-linking)** — 고분자를 화학적으로 **고정(set)**. 반응은 **되돌릴 수 없어** 가열하면 녹지 않고 분해되거나 탄다

### 열가소성 고분자 (TP)
- 고체 ↔ 점성 액체를 **반복해도 열화되지 않는다** — 가열 시 **가교되지 않는** 선형·분지 거대 분자이기 때문
- 기계적 성질: 낮은 탄성 계수 / 인장 강도는 **금속의 약 10 %** / 평균적으로 큰 연성이지만 범위가 매우 넓다(PS 1 % ~ PP 500 % 이상)
- 제품: 성형·압출품, 섬유·필라멘트, 필름·시트, 포장재, 페인트·바니시
- 원료는 보통 **분말이나 펠릿(pellets)** 형태로 공급 → 사출·압출기의 호퍼로 들어간다

### 열경화성 고분자 (TS)
- **고도로 가교된 3차원 공유 결합 구조**. 가교 반응을 **경화(curing, setting)** 라 한다
- 성형된 부품은 사실상 **하나의 거대 분자**. 항상 비정질이며 유리 전이 온도를 보이지 않음
- 성질: 강직(E가 TP의 2 ~ 3배), 취성, 용제에 덜 녹음, 높은 사용 온도, **재용융 불가**(분해·연소)
- 가교 활성화 방식: 온도 활성화 · 촉매 활성화 · 혼합 활성화
- **경화는 원료를 공급하는 화학 공장이 아니라 부품을 만드는 가공 공장에서 일어난다** ← TP와의 결정적 차이

### 탄성체 (Elastomers)
- 비교적 낮은 응력에서 **큰 탄성 변형**(일부는 500 % 이상)이 가능하고 원래 형상으로 복원
- 탄성의 두 근거: ① 늘어나지 않은 상태에서 분자가 심하게 **꼬여(kinked)** 있음 ② **가교 정도가 열경화성보다 훨씬 낮음**
- **가황(vulcanization)** = 탄성체를 가교하는 경화 처리. 전형적 가교는 **탄소 100개당 1 ~ 10개**
- **천연고무(NR)** = 폴리이소프렌. 식물의 **라텍스**(폴리이소프렌 약 1/3의 수중 에멀션)에서 물을 제거해 얻음
- **합성고무** — 세계대전기 NR 조달난이 계기. 현재 톤수는 NR의 3배 이상. 대표는 **SBR**(부타디엔 + 스티렌 공중합체). 주 원료는 석유
- **열가소성 탄성체(TPE)** — 탄성이 화학적 가교가 아니라 **연질상·경질상의 물리적 결합**에서 비롯. 고온 강도·크리프 저항은 부족. 제품: 신발, 고무 밴드, 압출 튜브, 전선 피복, 성형 자동차 부품(타이어 제외)
- 강성: 천연고무 < 가황 고무 < 경질 고무 — 가교가 많아질수록 $\sigma$–$\varepsilon$ 곡선이 가팔라진다

## 2-4 복합재료 (Composite Materials)

### 정의와 장단점
- **둘 이상의 서로 다른 상(phase)** 으로 이루어져, 그 조합이 구성 성분과 다른 종합 성질을 만드는 재료 시스템

| 장점 | 단점·한계 |
|---|---|
| 매우 강하고 강직하면서 가벼울 수 있음 | 많은 경우 성질이 **이방성(anisotropic)** — 장점일 수도 단점일 수도 |
| 피로 성질이 일반 공업용 금속보다 대체로 우수 | 고분자 기반은 화학물질·용제에 침식 |
| 인성도 더 큰 경우가 많음 | 일반적으로 고가 — 성형 제조법이 느리고 비싸다 |

### 구성 요소
- **1차상(primary phase)** = **기지(matrix)** — 전체 형태 제공, 2차상 고정, 하중 분담
- **2차상(secondary phase)** = **강화재(reinforcing agent)** — 1차상을 강화

| 2차상 형태 | 특징 |
|---|---|
| 섬유 fibers | 필라멘트, 보통 원형 단면 — **이방성** 설계 가능 |
| 입자 particles | 미시 ~ 거시 크기 — 무작위 분포 → 보통 **등방성** |
| 플레이크 flakes | 2차원의 작고 평평한 판 — 역시 등방성 |

### 기지 재료로 분류한 세 범주

| 범주 | 기지 | 예 |
|---|---|---|
| **MMC** 금속 기지 | 금속 | **서멧(cermets)** — 대표적으로 초경합금 |
| **CMC** 세라믹 기지 | $\mathrm{Al_2O_3}$, SiC 등 | 세라믹에 섬유를 매립해 인성 보완 |
| **PMC** 고분자 기지 | 고분자 수지 | **FRP**, 카본 블랙 강화 고무, 대부분의 플라스틱 성형 재료 |

### 섬유 — 강도 향상의 가장 큰 기회
- 직경 약 0.0025 ~ 0.13 mm의 필라멘트. **필라멘트 형태가 덩어리(bulk)보다 훨씬 강하다**
  - 직경이 작아지면 ① 재료가 **섬유 축 방향으로 배향**되고 ② **구조 결함의 확률이 크게 감소**
- **연속 섬유** — 하중이 전달되는 연속 경로 제공 / **불연속 섬유** — 잘게 자른 것($L/D \approx 100$)
- **위스커(whiskers)** — 머리카락 같은 단결정 불연속 섬유, 직경 0.001 mm까지, 매우 높은 강도
- 섬유 재료: **유리**(가장 널리 쓰임) · **탄소**(높은 E) · **붕소**(매우 높은 E) · 케블라 · $\mathrm{Al_2O_3}$ · SiC

### MMC — 서멧과 초경합금
- **서멧(cermet)** = 금속 기지에 세라믹이 포함된 MMC. 세라믹이 **부피의 최대 96 %** 를 차지하기도 한다. 가공 시 고온에서의 약간의 용해도가 결합을 강화
- **초경합금(cemented carbides)** = 하나 이상의 탄화물을 금속 기지에 결합
  - 탄화물: **WC**, TiC, $\mathrm{Cr_3C_2}$ (TaC 등은 덜 일반적)
  - 금속 결합제: 보통 **Co** 또는 **Ni** → 대표 제품이 WC–Co 절삭 인서트

### CMC · PMC · FRP
- **CMC** — 세라믹의 장점(높은 강성·경도·고온 경도·압축 강도·낮은 밀도)은 유지하고 약점(낮은 인성·인장 강도, 열균열)을 섬유로 보완하려는 시도
- **PMC** — 상업적으로 MMC·CMC보다 중요
- **FRP(섬유 강화 고분자)** = 고분자 기지에 고강도 섬유를 매립한 PMC
  - 기지: 보통 **불포화 폴리에스터·에폭시** 같은 열경화성. 나일론·PC·PS·PVC 같은 열가소성도 가능
  - 주요 섬유: 유리(특히 **E-glass**, 가장 일반적), 탄소, 케블라 49
  - 가장 널리 쓰이는 형태는 **적층 구조(laminar structure)** — 얇은 층을 쌓아 접합
  - **층마다 섬유 방향을 달리하면**(예 0°/±45°/90°/±45°/0°) 원하는 수준의 **이방성을 설계**할 수 있다
- FRP 용도: 항공우주(Boeing 787 — 동체·날개 상당 부분이 CFRP), 자동차 차체 패널·트럭 캡, 스포츠·레저(선체, 낚싯대, 라켓, 골프 샤프트, 헬멧, 스키, 활)

> 동체를 판이 아닌 **하나의 통(barrel)** 으로 만들면 층별 섬유 방향 설계를 동체 전체에 연속 적용할 수 있고, 접합부·리벳이 줄어 무게와 응력 집중이 감소한다.

## 자주 하는 실수
- 강과 주철의 경계를 헷갈림 → **강 0.02 ~ 2.11 % C, 주철 2.1 ~ 4 % C + Si 1 ~ 3 %**
- AISI `YYXX`의 뒤 두 자리를 %로 읽음 → **1/100 % 단위**(1020 = 0.20 % C)
- 회주철과 연성주철을 조성 차이로만 설명 → 핵심은 **흑연의 형태**(편상 vs 구상)와 Mg·Ce 처리
- 탄성체와 열경화성을 "둘 다 가교"라며 같이 묶음 → 다른 것은 **가교의 정도**
- "고분자는 전도도가 낮아서 한계" → 낮은 전도도는 **성질(절연체로 장점)**, 한계인 것은 **낮은 강성·강도·사용 온도·점탄성**
- 복합재료를 강화재로 분류 → 분류 기준은 **기지(matrix) 재료**

## 학습 확인
- 강과 주철을 나누는 탄소 함량 범위는? → 강 0.02 ~ 2.11 %, 주철 2.1 ~ 4 % + Si 1 ~ 3 %
- 모든 스테인리스강의 주 합금 원소와 내식성의 원리는? → **Cr 15 % 이상**, 표면의 얇고 치밀한 **산화막**
- 전통 세라믹·뉴 세라믹·유리의 구별 기준은? → 자연 광물 기반 / 합성·화학적으로 단순 / **비정질**
- 결정화 유리가 원래 유리보다 강한 이유는? → 핵 생성 + 결정 성장의 두 단계 열처리로 **결정립이 매우 작은** 다결정 구조, 기공 없음
- 탄성체와 열경화성 수지의 성질이 다른 이유는? → **가교 정도**(탄소 100개당 1 ~ 10개 vs 3차원 망 구조)
- 서멧은 어느 범주인가? → 금속 기지 + 세라믹 입자이므로 **MMC**(대표: WC–Co 초경합금)
