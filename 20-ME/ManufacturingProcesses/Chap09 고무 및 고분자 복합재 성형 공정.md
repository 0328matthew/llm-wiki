## 한 줄 요약
고무 가공은 **가황 전에는 흐르게 하고 가황 후에는 되돌아오게 만드는 과정**이며, 고분자 복합재 가공은 **매트릭스와 보강 섬유를 결합하면서 섬유 방향·기포·경화를 제어하는 과정**이다. 고무는 `원료 → 배합 → 혼련 → 성형 → 가황`, 복합재는 제품 크기·생산량·형상과 요구되는 섬유 방향에 따라 개방 금형·폐쇄 금형·연속 섬유 공정을 선택한다.

---

## 9-1 고무 제품의 생산 흐름

```text
원료 생산 → 배합 → 혼련 → 성형 → 가황
```

| 단계 | 하는 일 | 핵심 관리 항목 |
|---|---|---|
| 원료 생산 | 천연 고무 또는 합성 고무 준비 | 원료의 성질과 균일성 |
| 배합 | 황·충전재·보호제 등을 처방 | 요구 성능에 맞는 조성 |
| 혼련 | 첨가제를 고무에 균일하게 분산 | 온도 상승과 조기 가황 방지 |
| 성형 | 압출·캘린더링·코팅·금형 성형 | 형상과 치수, 보강재 배치 |
| 가황 | 사슬 사이를 가교해 최종 물성 형성 | 시간·온도·압력과 가교 밀도 |

### 천연 고무와 합성 고무

| | 천연 고무 NR | 합성 고무 SR |
|---|---|---|
| 출발점 | 고무나무의 라텍스 | 석유계 원료의 중합 |
| 주성분·설계 | 주성분은 폴리아이소프렌 | 용도에 맞춰 내열·내유·내후성 설계 |
| 공급 과정 | 응고·압연·세척·건조 후 베일 | 화학사가 원료 고무를 생산해 가공업체에 공급 |

천연 고무의 생산 순서는 다음과 같다.

```text
라텍스 채취 → 개미산 등으로 약 12시간 응고 → 롤 압연·세척 → 훈연 또는 열풍 건조 → 등급 분류·출하
```

- 라텍스는 **폴리아이소프렌 미립자의 콜로이드 분산액**이다.
- 천연 고무는 농산물이지만 완제품 생산에는 화학 반응과 기계 가공이 함께 필요하다.

## 9-2 배합과 혼련

### 배합제의 역할

| 배합제 | 역할 |
|---|---|
| **가황제** | 황·과산화물 등. 고분자 사슬 사이에 가교 형성 |
| **보강 충전재** | 카본 블랙·실리카. 인장 강도와 내마모성 향상 |
| **증량재** | 값싼 충전재로 부피를 늘려 원가 절감 |
| **산화 방지제** | 산소·오존·열에 의한 열화 지연 |
| **가소제·안료** | 가공성, 경도, 색 조절 |
| **발포제** | 기체를 발생시켜 다공성 고무 폼 형성 |

> **카본 블랙**은 단순한 검은색 안료가 아니다. 타이어의 인장 강도와 내마모성을 크게 높이는 핵심 보강재다. 흰색 제품에는 실리카·점토 계열 충전재를 사용한다.

### 두 단계 혼련
고무는 점도가 매우 높아서 첨가제를 고르게 분산하려면 강한 기계적 작업이 필요하고, 그 과정에서 온도가 약 **150 °C**까지 오를 수 있다. 가황제를 처음부터 넣으면 혼련기 안에서 **스코치(scorch, 조기 가황)** 가 일어날 수 있으므로 혼련을 나눈다.

1. 카본 블랙과 비가황 첨가제를 섞어 **마스터배치(masterbatch)** 를 만든다.
2. 재료를 식혀 보관·이송한다.
3. 실제 성형 직전에 가황제를 넣어 다시 혼련한다.

| 혼련기 | 특징 |
|---|---|
| **2롤 밀(two-roll mill)** | 개방형. 작업자가 재료를 관찰하고 조절하기 쉬움 |
| **밴버리 혼련기(Banbury mixer)** | 밀폐형 내부 혼련기. 생산성과 균일성이 높음 |

## 9-3 고무 성형 공정

| 공정 | 제품·용도 | 공정상 특징 |
|---|---|---|
| **압출** | 호스·트레드·실 | 짧은 $L/D$로 체류 시간과 조기 가황을 억제 |
| **캘린더링** | 시트·벨트·타이어 플라이 | 롤 간격을 단계적으로 줄여 두께 제어 |
| **코팅** | 직물·금속 코드 보강층 | 보강재 표면에 고무를 입혀 결합 |
| **금형 성형** | 개별 형상 제품 | 압축·트랜스퍼·사출, 금형 안에서 성형과 가황을 함께 수행 |

- 공정 이름은 플라스틱 가공과 같아도 고무는 **조기 가황·다이 스웰·후가황**을 함께 관리해야 한다.
- 캘린더 출구 시트는 탄성 회복 때문에 최종 롤 간격보다 조금 두꺼워질 수 있다.

### 가황 (Vulcanization)
가황은 엘라스토머 분자 사슬 사이에 **가교 결합**을 만드는 처리다.

```text
가황 전: 사슬이 미끄러짐 → 점성이 크고 영구 변형
가황 후: 사슬이 가교됨 → 늘어난 뒤 원래 형상으로 회복
```

- 가황으로 강도와 강성은 증가하지만 큰 탄성 변형 능력은 유지된다.
- 적은 가교는 **연질 고무**, 많은 황과 높은 가교 밀도는 **경질 고무**를 만든다.
- 초기 Goodyear 조건은 황 약 8 phr, 140 °C, 약 5시간이었지만 현대 공정은 촉진제를 이용해 약 15~20분 수준까지 단축한다.

> 가황과 열가소성 수지의 냉각은 다르다. 냉각은 대체로 가역적인 물리 변화지만 가황은 사슬 구조를 바꾸는 **비가역적 화학 반응**이다.

## 9-4 타이어의 구조와 생산

타이어는 고무 한 덩어리가 아니라 트레드·사이드월·카커스 플라이·벨트·비드 등 약 **50개 부품**을 조립한 복합 구조다. 비드 코일은 타이어가 림에 단단히 걸리도록 지지한다.

### 세 가지 타이어 구조

| 구조 | 플라이·벨트 배치 | 특징 |
|---|---|---|
| **다이애거널 플라이** bias/diagonal | 대각 플라이가 서로 교차, 별도 벨트 없음 | 단순하지만 발열과 변형이 큼 |
| **벨티드 바이어스** | 대각 플라이 위에 둘레 방향 벨트 추가 | 바이어스 구조를 벨트로 보강 |
| **래디얼** radial | 카커스 플라이가 반경 방향, 트레드 아래 둘레 방향 벨트 | 트레드 지지가 좋고 현대 승용차의 표준 |

### 생산 순서

```text
트레드·플라이·벨트·비드 프리폼
→ 빌딩 드럼에서 카커스·사이드월·트레드 적층
→ 금형 폐쇄
→ 내부 다이어프램 팽창·가열
→ 최종 형상·트레드 무늬 형성 + 가황
```

가황은 마지막의 단순한 별도 처리라기보다 **금형 안에서 성형과 동시에 여러 부품을 일체화하는 단계**다.

### 다른 고무 제품과 TPE

- **벨트** — 고무의 유연성과 섬유·강선의 낮은 신율을 결합
- **호스** — 내부 튜브 + 보강층 + 외피. 압력·유체·환경에 따라 각 층의 배합을 달리함
- **신발** — 밑창·굽·갑피를 압축 또는 사출 성형한 뒤 접착·가황

| | 가황 고무 | TPE (thermoplastic elastomer) |
|---|---|---|
| 구조·거동 | 영구 가교 네트워크 | 실온에서는 고무처럼, 가열하면 열가소성 수지처럼 흐름 |
| 장점 | 우수한 내열성과 탄성 | 압출·사출로 고속 가공, 재가공·재활용이 비교적 쉬움 |
| 재용융 | 불가능 | 가능 |

## 9-5 고분자 매트릭스 복합재의 구성

고분자 매트릭스 복합재(PMC, polymer matrix composite)는 **매트릭스가 묶고 보강재가 버티는 재료**다.

| 구성 | 역할·재료 |
|---|---|
| **매트릭스(matrix)** | 섬유 고정, 섬유 사이 하중 전달, 수분·마모·충격으로부터 보호. 주로 불포화 폴리에스터·에폭시 같은 열경화성 수지 |
| **보강재(reinforcement)** | 강도와 강성 담당. 유리·탄소·아라미드 섬유, 입자·플레이크 등 |

복합재의 성능은 재료 이름만으로 정해지지 않는다. 보강재의 **형태·함량·방향**이 핵심이다.

### 섬유 형태

| 형태 | 정의·방향성 |
|---|---|
| **로빙(roving)** | 꼬지 않은 연속 필라멘트 다발 |
| **얀(yarn)** | 섬유를 꼬아 만든 실 |
| **직물(fabric)** | 얀 또는 로빙을 직조해 주로 두 방향 보강 |
| **매트(mat)** | 단섬유를 무작위로 배열 |
| **프리폼(preform)** | 제품 형상에 맞게 보강재를 미리 배열한 형태 |

### SMC와 프리프레그

| | SMC (sheet molding compound) | 프리프레그 (prepreg) |
|---|---|---|
| 보강재 | 무작위 **절단 유리섬유** | 보통 **연속 섬유** |
| 수지 상태 | 열경화성 수지·충전재와 혼합해 약 6.5 mm 시트로 제조 | 부분 경화된 수지를 미리 함침 |
| 형태 | 절단해 압축 금형에 장입 | 테이프·교차 적층 시트·직물 |
| 강점 | 빠른 금형 충전과 중대량 생산 | 섬유 방향을 이용한 높은 방향성 성능 |

복합재 공정은 서로 다른 재료를 결합하면서 **기포 제거·섬유 방향 유지·수지/섬유비 관리·완전 경화**를 동시에 해야 하므로 느리고 노동집약적일 수 있다.

## 9-6 개방 금형 공정

### 개방 금형과 폐쇄 금형의 선택

| | 개방 금형 | 폐쇄 금형 |
|---|---|---|
| 금형 | 한쪽 금형 면 | 두 금형 면 사이 |
| 적합한 생산 | 대형·소량 | 반복 생산·중대량 |
| 표면 | 한쪽만 금형 품질 | 양면 마감이 우수 |
| 비용·정밀도 | 금형비 낮고 노동 의존도가 큼 | 금형비가 높지만 공차·생산률 우수 |
| 대표 공정 | 핸드 레이업·스프레이업·자동 테이프 적층 | 압축·트랜스퍼·사출·RTM/RRIM |

> 제품이 크고 생산량이 적을수록 개방 금형, 양면 외관·공차·반복 생산이 중요할수록 폐쇄 금형이 유리하다.

### 핸드 레이업 (Hand Lay-Up)

```text
이형제 → 젤 코트 → 수지·섬유 적층 → 롤링·기포 제거 → 경화 → 탈형·트리밍
```

- **이형제** — 완제품이 금형에서 분리되도록 함
- **젤 코트** — 외관과 표면 보호
- **적층·롤링** — 섬유를 수지로 함침하고 기포 제거
- 보트 선체·수영장·대형 탱크처럼 크고 수량이 적은 제품에 적합
- 강도는 섬유 배향과 기포 제거 품질에 크게 좌우됨

### 스프레이업과 자동 테이프 적층

| 공정 | 특징 |
|---|---|
| **스프레이업** | 수지와 절단 섬유를 동시에 분사한 뒤 롤러로 다짐. 핸드 레이업보다 빠르지만 무작위 섬유여서 같은 두께의 강도는 낮음 |
| **자동 테이프 적층** | 프리프레그 테이프를 프로그램된 경로로 적층. 방향을 정밀 제어해 항공기 같은 대형 고성능 구조에 적합 |

### 경화 방법

| 방법 | 특징 |
|---|---|
| **실온 경화** | 대형 핸드 레이업·스프레이업에 사용. 설비는 단순하지만 느림 |
| **오븐·적외선** | 온도를 제어해 반응을 촉진하고 경화 시간 단축 |
| **진공 백** | 공기와 휘발분을 빼고 대기압으로 적층을 눌러 층간 접촉과 섬유 체적률 향상 |
| **오토클레이브** | 밀폐 챔버에서 열·진공·외부 압력을 제어해 기포가 적고 치밀한 제품 생산 |

가황과 마찬가지로 열경화성 복합재의 경화도 대개 **비가역적 가교 반응**이다.

## 9-7 폐쇄 금형 공정

| 공정 | 장입재·작동 | 대표 특성 |
|---|---|---|
| **압축 성형** | SMC·BMC·프리폼을 하부 금형에 놓고 가열·가압 | 자동차 패널 등 중대량 생산 |
| **트랜스퍼 성형** | 열경화성 수지와 단섬유 장입재를 챔버에서 가열해 닫힌 공동으로 이송 | 비교적 복잡한 형상 |
| **사출 성형** | 열가소성 또는 열경화성 수지에 단섬유를 섞어 사출 | 빠른 대량 생산 |

일반 사출 성형에는 주로 **단섬유**를 쓴다. 연속 섬유는 회전 스크루에서 잘리고 용융체의 흐름을 방해하기 때문이다.

### 강화 반응 사출 성형 (RRIM)

```text
저점도 반응성 수지 두 성분 → 급속 혼합 → 보강재 추가·주입 → 금형 내 중합·경화 → 취출
```

- 낮은 점도 덕분에 큰 공동을 낮은 압력으로 채울 수 있다.
- 대형·복잡한 외장 부품에 적합하고, 섬유로 강도와 강성을 높인다.
- 혼합비·반응 시간, 섬유 분포와 방향, 금형 내 가스와 미충전을 관리해야 한다.

## 9-8 연속 섬유 공정

### 필라멘트 와인딩 (Filament Winding)
수지에 함침한 **연속 로빙**을 회전하는 맨드릴 주위에 감는다. 캐리지가 축 방향으로 이동하면서 원주·나선·극방향의 감기 패턴을 만든다.

- 맨드릴 회전 속도와 캐리지 이동 속도의 비가 **감기 각도**를 결정한다.
- 섬유를 제품의 주응력 방향에 효율적으로 배치할 수 있다.
- 파이프·압력 용기·로켓 모터 케이스 같은 **회전 대칭 중공 제품**에 적합하다.
- 성능 변수: 섬유 장력, 감기 각도, 수지 함량, 층간 기포
- 경화가 끝나면 맨드릴을 제거한다.

### 풀트루전 (Pultrusion)

```text
로빙·매트 공급 → 수지 함침 → 프리포밍 → 가열 다이 → 인발 → 절단
```

- 압출(extrusion)은 재료를 **밀지만**, 풀트루전은 연속 섬유를 **당긴다(pull)**.
- 길이 방향으로 연속 섬유가 놓여 **축 방향 강도**가 매우 높다.
- 봉·튜브·채널·I형재처럼 길고 **단면이 일정한 제품**에 적합하다.
- 대표 재료는 불포화 폴리에스터·에폭시·실리콘과 약 30~70%의 E-유리다.

### 필라멘트 와인딩과 풀트루전 비교

| | 필라멘트 와인딩 | 풀트루전 |
|---|---|---|
| 기본 동작 | 회전 맨드릴에 감기 | 가열 다이를 통해 당기기 |
| 대표 형상 | 회전 대칭 중공 형상 | 긴 일정 단면 |
| 주 섬유 방향 | 원주·나선·극방향 | 길이 방향 |
| 대표 제품 | 압력 용기·파이프 | 봉·튜브·채널·I형재 |

### 변형 공정

- **풀포밍(pulforming)** — 풀트루전 뒤에 후속 성형을 추가해 직선·일정 단면이라는 제약을 완화하고 길이 방향 곡률이나 단면 변화를 부여
- **튜브 롤링(tube rolling)** — 프리프레그를 맨드릴에 감아 압밀·경화

## 9-9 FRP의 절단

| | 경화 전 | 경화 후 |
|---|---|---|
| 대상 | 프리프레그·프리폼·SMC | 완전히 경화된 복합재 |
| 공구 | 칼·가위·전동 전단·스틸 룰 다이·레이저·워터젯 | 초경·다이아몬드 공구·고압 워터젯 |
| 주요 문제 | 적층·금형 크기와 섬유 흐트러짐 | 높은 마모성, 분진, 박리, 섬유 풀아웃 |

유리·탄소 섬유는 절삭 공구에 매우 마모성이 크다. 따라서 가능하면 적층·성형 단계에서 **최종 형상에 가깝게 만들고 경화 후 절단량을 줄이는 것**이 좋다.

## 핵심 비교 정리

| 비교 | 구분 기준 |
|---|---|
| 고무 원료 | NR은 라텍스에서, SR은 석유계 원료의 중합으로 생산 |
| 가황 전 ↔ 후 | 사슬 미끄러짐·영구 변형 ↔ 가교 네트워크·탄성 회복 |
| 가황 고무 ↔ TPE | 비가역 영구 가교 ↔ 가열 시 재성형 가능 |
| 개방 ↔ 폐쇄 금형 | 대형·소량·한쪽 표면 ↔ 반복 생산·양면 품질·정밀도 |
| 스프레이업 ↔ 자동 테이프 적층 | 무작위 절단 섬유·속도 ↔ 연속 섬유 방향 제어·고성능 |
| SMC ↔ 프리프레그 | 무작위 단섬유 시트 ↔ 부분 경화 수지가 함침된 연속 섬유 |
| 필라멘트 와인딩 ↔ 풀트루전 | 회전체에 감기 ↔ 일정 단면을 당기기 |

## 학습 확인

1. **완제품 고무를 만드는 다섯 단계를 쓰고 가황의 역할을 설명하라.**

   원료 생산 → 배합 → 혼련 → 성형 → 가황. 가황은 분자 사슬을 가교해 강도와 강성을 높이면서 큰 탄성 변형 뒤의 회복 능력을 부여한다.

2. **두 단계 혼련을 하는 이유는 무엇인가?**

   혼련 중 열과 전단으로 가황 반응이 너무 일찍 시작되는 스코치를 막기 위해, 먼저 비가황 첨가제로 마스터배치를 만들고 성형 직전에 가황제를 넣는다.

3. **래디얼 타이어와 다이애거널 플라이 타이어의 구조 차이는 무엇인가?**

   래디얼은 플라이가 반경 방향이고 트레드 아래 둘레 방향 벨트가 있다. 다이애거널은 대각 플라이가 교차하고 별도 벨트가 없다.

4. **프리프레그와 SMC의 보강 섬유 형태는 어떻게 다른가?**

   프리프레그는 보통 연속 섬유에 부분 경화 수지를 함침한 중간재이고, SMC는 수지·충전재·무작위 절단 유리섬유를 시트로 만든 성형 재료다.

5. **필라멘트 와인딩과 풀트루전은 각각 어떤 형상과 섬유 방향에 적합한가?**

   와인딩은 회전 대칭 중공 제품에 섬유를 원주·나선 방향으로 놓기 좋고, 풀트루전은 일정 단면의 긴 제품에 연속 섬유를 길이 방향으로 배치한다.
