## 정의
> 관심 물체를 주변과 분리하여, **그 물체에 작용하는 모든 외력과 모멘트만**을 그린 도식.

## 직관
- "이 물체 입장에서 받는 힘만 다 그려본다"
- 정역학 문제 풀이의 **거의 모든 시작점**
- 잘못 그린 FBD → 식은 맞아도 답은 틀림

## 작도 절차
1. **물체를 격리** — 주변 구조에서 분리하여 외곽선만 남김
2. **외력 표시** — 중력(W), 외부 하중(P, F)
3. **반력 표시** — 지지 조건에 따라
   - Roller: 면에 수직 반력만
   - Pin: 두 직교 반력
   - Fixed: 두 반력 + 모멘트
4. **마찰력** — 운동/임박 방향의 **반대**로
5. **좌표축** 설정

## 평형 방정식 (2D)
$$
\sum F_x = 0, \quad \sum F_y = 0, \quad \sum M_O = 0
$$
미지수 3개까지 정해진 정정 구조(determinate)에서 풀이 가능.

## 자주 하는 실수
- 내력을 외력으로 잘못 그림 (예: 트러스 부재력은 분리해야 보임 → [[트러스 해석]])
- 마찰력 방향 반대로
- 반력 부호 가정 후 음수 나와도 **물리적으로 맞는** 것임을 잊음

## LLM × 이 주제
- 시험 문제 사진 입력 → LLM이 FBD 단계별 작도 안내 (Vision + CoT)
- 작도 후 평형식 자동 생성 (SymPy로 풀이) → [[Tool Use]]
