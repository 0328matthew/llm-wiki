## 한 줄 요약
> LLM에게 발표 대본을 주면 PPT 구성·레이아웃·디자인을 알아서 설계하게 하는 개인 워크플로우와 디자인 철학.

## 디자인 철학 (내 선호)
- **컨셉:** 깔끔하고 세련된 스타일. 과하지 않고 정돈된 레이아웃.
- **용도:** 주로 기술적 발표(technical presentation). 전문적이되 이해하기 쉽게.
- **언어/단어:** 쉬운 단어 위주. 어렵거나 생소한 기술 용어는 가능하면 풀어서 표현.
- **이미지:** 인터넷에서 사진을 적극적으로 활용. 텍스트만 가득한 슬라이드 지양, 시각 자료를 풍부하게.

## 협업 방식 (내가 LLM에게 일을 맡기는 순서)
1. **내가 대본(스크립트)을 제공** — 발표 시간/문단별 타임라인 포함하면 좋음
2. **LLM이 구성 설계** — 슬라이드 수, 흐름, 섹션 배분, 슬라이드별 제목을 자율적으로 결정
3. **내가 구성안 검토 후 확정** — 표 형태로 슬라이드별 제목/내용/시간 제시받고 수정
4. **확정 후 제작** — LLM이 실제 .pptx 생성

## 제작 기술 메모
- 도구: `pptxgenjs` (Node.js) 로 코드 기반 생성 → Claude Code의 `pptx` skill 사용
- 다크 우주/프리미엄 테마 등 주제에 맞는 색 팔레트를 먼저 고정
- 헤더/본문 폰트 페어링 (예: Georgia + Calibri)
- 슬라이드당 텍스트 최소화, 키워드 + 이미지 중심
- 이미지는 공개 도메인(NASA, Wikimedia Commons 등) URL 직접 삽입 가능
- ⚠️ 이 PC에는 현재 node 미설치 — pptxgenjs 실행하려면 Node.js 환경 필요

## 디자인 안티패턴 (피할 것)
- 제목 밑 장식용 밑줄(accent line) — AI 슬라이드 티
- 장식용 풀폭 컬러 바/리본
- 텍스트만 있는 슬라이드
- 본문 가운데 정렬 (제목만 가운데, 본문은 좌측 정렬)
- 크림/베이지 기본 배경 (흰색 또는 브랜드 팔레트 사용)
