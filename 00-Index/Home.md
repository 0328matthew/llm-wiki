# 🏠 LLM Wiki — Home

> 기계공학 학부생의 LLM × 공학 학습 위키.
> 이 페이지가 모든 노트의 시작점.

## 주제별 허브 (MOC)
- 🤖 [[LLM-MOC]] — LLM 기초, 프롬프트, 에이전트, 도구
- ⚙️ [[ME-MOC]] — 기계공학 (4역학 + 기구학 + 재료공학)
- 📐 [[Math-MOC]] — 응용수학 (수치해석, 미분방정식)
- 💻 [[CS-MOC]] — C++ 프로그래밍 (포르잔 기준: 객체지향 접근 + 구조적 접근)
- 🧠 [[Philosophy-MOC]] — 동·서양 사상가의 사상·논증·논리·한계 (나만의 철학자)

## 작업 공간
- 🧪 [[30-Projects]] — 진행 중·구상 중 프로젝트 (ME × LLM)
- 📄 [[40-Papers]] — 논문/자료 정리
- 📆 `50-Daily/` — 매일 학습 일지 (Daily Note)
- 🧱 `90-Templates/` — 새 노트 시작 시 사용
- 🖼️ `99-Attachments/` — 이미지·PDF 등 첨부

## 활용 방식
1. **새 개념 학습** → 해당 MOC로 가서 폴더 안에 `[[새 노트]]` 추가 → `concept` 템플릿 적용
2. **논문 읽음** → `40-Papers/`에 `paper` 템플릿으로 정리
3. **프로젝트 시작** → `30-Projects/`에 `project` 템플릿으로 작성
4. **하루 한 줄이라도** → `50-Daily/`에 오늘 날짜 노트 (Daily Note 핫키)

## 워크플로우 단축키 (Obsidian 기본)
- `Ctrl+N` — 새 노트
- `Ctrl+O` — 빠른 전환 (Quick Switcher)
- `Ctrl+P` — 명령 팔레트
- `Ctrl+E` — 편집/미리보기 토글
- `Ctrl+G` — 그래프 뷰

## Git 동기화
- `obsidian-git` 플러그인 설치돼 있음 → `Ctrl+P` → "Git: Commit all changes" / "Git: Push"
- 또는 외부에서 `git add . && git commit -m "..." && git push`
