## 한 줄 요약
1계 ODE 풀이 5가지 표준 기법: **방향장 → 분리변수 → 선형(적분인자) → 완전미분 → 치환 → 수치해**. 어떤 형태로 변형하면 어떤 기법이 통하는지가 핵심.

---

## 2.1 정성적 분석 — 해를 구하지 않고 보는 법

### 방향장 (Direction Field / Slope Field)
$y' = f(x, y)$에서 $(x,y)$ 평면 각 점에 기울기 $f(x,y)$를 짧은 선분으로 그림 → 해곡선의 형태 시각화.

### 자율 1계 ODE
$y' = f(y)$ — 우변에 $x$가 없는 경우:
- **임계점(critical point)**: $f(c) = 0$인 $y = c$ → 상수해
- 임계점 사이에서 부호 분석으로 단조 증가/감소 판정
- **안정성**: attractor / repeller / semi-stable

---

## 2.2 분리변수형 (Separable)
형태:
$$
\frac{dy}{dx} = g(x) h(y)
$$
풀이:
$$
\int \frac{dy}{h(y)} = \int g(x)\,dx + C
$$

예: $\dfrac{dy}{dx} = -\dfrac{x}{y}$ → $y\,dy = -x\,dx$ → $\dfrac{y^2}{2} = -\dfrac{x^2}{2} + C$

> 주의: $h(y) = 0$인 $y$는 분리 과정에서 잃어버릴 수 있는 **특이해** — 따로 확인.

---

## 2.3 선형 1계 ODE (Linear) — **적분인자**
표준형:
$$
\frac{dy}{dx} + P(x)\,y = f(x)
$$

**적분인자**:
$$
\mu(x) = \exp\!\left(\int P(x)\,dx\right)
$$
양변에 $\mu$ 곱하면 좌변이 $\dfrac{d}{dx}[\mu(x)\,y]$로 완전미분 → 적분.

**해**:
$$
\boxed{\;y = \frac{1}{\mu(x)}\left[\int \mu(x)\,f(x)\,dx + C\right]\;}
$$

---

## 2.4 완전미분형 (Exact Equations)
$M(x,y)\,dx + N(x,y)\,dy = 0$이 **완전**(exact)이려면:
$$
\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}
$$
이때 어떤 함수 $F(x,y)$가 존재해 $\dfrac{\partial F}{\partial x} = M, \dfrac{\partial F}{\partial y} = N$ → 해는 $F(x,y) = C$.

### 풀이 절차
1. $F = \int M\,dx + g(y)$
2. $\dfrac{\partial F}{\partial y} = N$ 조건으로 $g'(y)$ 결정
3. $g(y)$ 적분 → $F(x,y) = C$

### 적분인자로 만들기 (Non-exact → exact)
- $\dfrac{M_y - N_x}{N}$가 $x$만의 함수 → $\mu(x) = \exp\!\int \dfrac{M_y - N_x}{N}\,dx$
- $\dfrac{N_x - M_y}{M}$가 $y$만의 함수 → $\mu(y) = \exp\!\int \dfrac{N_x - M_y}{M}\,dy$

---

## 2.5 치환에 의한 풀이

### 동차(Homogeneous) DE
$M, N$이 같은 차수의 동차함수 → **$y = ux$** 치환:
$$
\frac{dy}{dx} = u + x\frac{du}{dx}
$$
→ $x, u$의 분리변수형으로 환원.

### Bernoulli 방정식
$$
\frac{dy}{dx} + P(x)y = f(x)\,y^n,\quad n \ne 0, 1
$$
**$u = y^{1-n}$** 치환 → $u$의 선형 1계 ODE:
$$
\frac{du}{dx} + (1-n)P(x)\,u = (1-n)f(x)
$$

### 일반 치환
$y' = f(Ax + By + C)$ → $u = Ax + By + C$.

---

## 2.6 수치해법 — Euler 방법
1계 IVP $y' = f(x,y),\ y(x_0) = y_0$을 수치적으로 근사:
$$
\boxed{\;y_{n+1} = y_n + h\,f(x_n, y_n)\;}
$$
- 1차 정확도, 단점: 작은 $h$ 필요
- 개선판:
  - **Improved Euler / Heun**: 평균 기울기 사용 (2차 정확도)
  - **Runge–Kutta 4**: 4단계 평균 (4차)

> LLM 활용: 자율 ODE에 대해 SymPy(해석해) + NumPy/SciPy(수치해) 병행 — 정확한 수치는 [[Tool Use]]로 위임.

## 풀이법 결정 플로우
1. $y' = g(x)h(y)$ 형태? → **분리변수**
2. $y' + P(x)y = f(x)$? → **선형 (적분인자)**
3. $M\,dx + N\,dy = 0$ + $M_y = N_x$? → **완전**
4. $M_y \ne N_x$지만 적분인자 가능? → **적분인자**
5. $M, N$ 동차? → $y = ux$
6. $y^n$이 있는 선형? → **Bernoulli**
7. 그 외 → 치환 시도 / 수치해

---

## 자주 하는 실수
- 적분인자 곱하기 전 $P(x)$의 부호 실수
- 완전미분에서 $g(y)$를 $g(x)$로 잘못
- 분리변수 시 $h(y) = 0$인 특이해 누락
- Bernoulli에서 $1-n$ 곱하기 누락
- Euler법에서 $h$가 너무 커서 불안정한데 알아채지 못함
