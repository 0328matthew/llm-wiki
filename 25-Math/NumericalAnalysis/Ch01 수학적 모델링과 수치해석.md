# Ch1. Mathematical Modeling, Numerical Methods, and Problem Solving

> **Part 1**: Modeling, Computers, and Error Analysis

## 1.1 A Simple Mathematical Model — 자유낙하 점퍼

### Governing Equation (뉴턴의 제2법칙)
스카이다이버에 작용하는 중력과 공기저항(드래그)의 균형에서:

$$\frac{dv}{dt} = g - \frac{c_d}{m}v^2$$

| 기호 | 의미 |
| --- | --- |
| $v$ | 하강 속도 (m/s) |
| $t$ | 시간 (s) |
| $g$ | 중력가속도 ($\approx 9.81\,\text{m/s}^2$) |
| $c_d$ | 항력 계수 (kg/m) |
| $m$ | 점퍼 질량 (kg) |

### 해석해 (Analytical Solution)
$v(0) = 0$ 초기조건에서:

$$v(t) = \sqrt{\frac{gm}{c_d}}\,\tanh\!\left(\sqrt{\frac{gc_d}{m}}\,t\right)$$

- 독립변수 $t$, 종속변수 $v(t)$
- 모수 $c_d$, $m$
- 강제함수 (forcing function) $g$

> 하지만 **대부분의 수학 모델은 해석해를 구할 수 없다** → 수치해(approximation)가 필요!

## Numerical Solution — Euler's Method

미분의 정의:
$$\frac{dv}{dt} = \lim_{\Delta t \to 0}\frac{\Delta v}{\Delta t}$$

이를 **finite difference**로 근사:
$$\frac{dv}{dt} \approx \frac{v(t_{i+1}) - v(t_i)}{t_{i+1} - t_i} = g - \frac{c_d}{m}v^2(t_i)$$

정리하면 **Euler 식**:
$$\boxed{v_{i+1} = v_i + \frac{dv_i}{dt}\Delta t}$$

→ **New value = Old value + Slope × Step size**

### 정확도 개선
- 스텝 사이즈 $\Delta t$를 작게 → 계산량 ↑ → 컴퓨터 필요
- 자세한 오차 분석은 [[Ch04 오차 분석과 반올림]] 참고

## 1.2 Conservation Laws in Engineering and Science

### Transient (과도) 해석
$$\frac{dv}{dt} = g - \frac{c_d}{m}v^2 \;\Longrightarrow\; v(t) = \sqrt{\frac{gm}{c_d}}\tanh\!\left(\sqrt{\frac{gc_d}{m}}t\right)$$

### Steady-state (정상상태) 해석
$$\frac{dv}{dt} = 0 \;\Longrightarrow\; mg = c_dv^2 \;\Longrightarrow\; v_{\text{terminal}} = \sqrt{\frac{gm}{c_d}}$$

이것이 **종단속도(terminal velocity)**.

### 공학별 보존법칙

| 분야 | 장치 | 원리 | 수학적 표현 |
| --- | --- | --- | --- |
| 화학공학 | Reactor | 질량보존 | $\Delta\text{mass} = \text{in} - \text{out}$ |
| 토목공학 | Structure | 운동량보존 | $\sum F_H = 0, \sum F_V = 0$ |
| 전기공학 | 회로 | 전하/에너지 보존 | Kirchhoff 법칙 |
| 기계공학 | 기계요소 | 에너지 보존 | $\Delta E = Q - W$ |
